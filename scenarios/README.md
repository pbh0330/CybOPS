# scenarios/ - 시나리오 데이터와 그 숫자의 출처

이 디렉터리의 시나리오는 **전부 가상 훈련 시나리오**다. 실제 부대편성·임무계획·자산대장을
쓰지 않았고, 어떤 파일도 실제 배치를 뜻하지 않는다. 화면의 워터마크
("가상 훈련 시나리오 · 실제 부대 배치 아님", ADR-0025)가 같은 말을 하고 끌 수 없다.

| 시나리오 | 망 | 시간축 | 출처 기록 |
|---|---|---|---|
| `tacnet-01` | 전술망(ADR-0012) | 있다(420분, 15분 간격) | [`tacnet-01/PROVENANCE.md`](tacnet-01/PROVENANCE.md) |
| `defnet-01` | 국방망(엔터프라이즈 유사) | 없다(단일 스냅샷) | [`defnet-01/PROVENANCE.md`](defnet-01/PROVENANCE.md) |

## 왜 PROVENANCE.md 가 있는가

CLAUDE.md 는 "검증되지 않은 수치를 확정 사실처럼 서술하지 않는다" 고 요구하는데
`mission.json` 의 숫자에는 출처가 하나도 붙어 있지 않았다. 필수도 0.7, 가중치 0.4,
지휘소 이동 30분, 좌표 (13500, 11700, 538) 이 공개 자료인지 교범 값인지 사람이 서사에 맞게
정한 값인지 파일만 봐서는 알 수 없었다. "이 필수도는 어디서 왔습니까" 에 답이 없는 상태였다.

**답은 대부분 "사람이 정했다" 다.** 그것을 그렇게 적는 것이 이 파일들의 일이다. 지어낸 값을
출처 있는 값처럼 쓰지 않는다.

## 출처 표기 어휘

PROVENANCE.md 의 모든 행은 아래 다섯 중 하나다.

| 표기 | 뜻 |
|---|---|
| **공개 자료** | 공개된 문서·표준·데이터셋에서 가져온 값. 무엇인지 적는다 |
| **유도값** | 다른 값에서 계산한 값. 계산식을 적는다. 인용이 아니다 |
| **도구 산출** | 이 저장소의 결정론적 도구가 만든 값. 재현 명령을 적는다 |
| **저작 가정** | 사람이 서사에 맞게 정한 값. 저장소에 그 선택의 근거 문서가 있다 |
| **출처 미상, 저작 가정** | 사람이 정한 값이고, 왜 그 값인지가 어디에도 기록돼 있지 않다 |

마지막 칸이 가장 많다. 그것이 현재 상태의 정확한 기술이다.

## 이 숫자들로 무엇을 주장할 수 있고 없는가

- **할 수 있다**: 구조에 관한 주장. "도달하지 못하는 이중화는 이중화가 아니다", "격리가
  공격보다 비쌀 수 있다", "기동에 의한 단절을 적의 소행으로 보고하면 안 된다". 이것들은
  값이 아니라 그래프와 전파 규칙의 성질이고, 값을 흔들어도 부호가 바뀌지 않는다.
- **할 수 없다**: 수치 자체에 관한 주장. "대대 지휘통제는 실제로 79% 저하된다" 는 문장은
  이 데이터로 쓸 수 없다. 79% 는 저작한 가중치의 함수다.
- 탐지 성능은 여기서 전혀 나오지 않는다. 합성 데이터의 한계는
  `docs/07-synthetic-data.md` 6절이 따로 적는다.

## 검사

`PROVENANCE.md` 는 산문이므로 그 자체로는 아무것도 강제하지 않는다. 강제하는 것은
검사기다.

```powershell
.\scripts\Test-ScenarioInvariants.ps1      # 시나리오가 자기 선언과 맞는지
.\scripts\Invoke-Gates.ps1                 # 위 검사를 포함한 전체 게이트
```

좌표가 선언된 extent 안에 있는지, 기동 구간이 `[0, horizon)` 을 빈틈없이 덮는지, 건물
배치가 서로 겹치지 않는지, 표시 좌표 변환의 실측 오차가 선언한 상한 안인지, 그리고
리플레이와 교전이 **스텝 묶음 크기에 독립인지**를 본다. 상세는
`ui/tools/verify-scenarios.mjs` 머리말에 있다.
