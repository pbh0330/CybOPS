## Global Constraints

- LLM 은 상태값을 결정하지 않는다(ADR-0003). 공격자 LLM 은 열거된 합법수 중 하나를 고를 뿐(기존), 참모 LLM 은 규칙 순위표를 **읽어 주기만** 한다. 참모 문장은 `history` 에 남지 않는다.
- 실행 경로 없음(ADR-0004). 격리는 모의 상태 변경뿐이고 사람이 버튼을 누른다.
- 인용 없는 LLM 문장은 `미검증` 표기(ADR-0009). 참모 문장은 `[F#]` 인용 필수.
- 빨강(`#ff4d5e`)은 공격 전용. 공격자 후보수(유령 화살표)는 공격자의 수이므로 빨강 계열 저불투명도. 격리 표기는 무채(흰 파선/이중선). 크롬 무채색.
- `attack.js` 의 기본 경로(옵션 없이 호출)는 바이트 단위로 같은 결과를 내야 한다. `node ui/tools/redteam.mjs` 를 돌릴 필요는 없지만 `node ui/tools/parity.mjs` 는 통과해야 한다.
- 격리의 의미: 임무 수치에는 `compromise=1`, 공격자에게는 없는 자산(거점·도달·표적 제외), 턴당 1회, 영구.
- hold 점수 = Σ_turns Σ_missions (저하도 × 1/priority), 낮을수록 좋음, 종료 시 P1 < 0.5 이면 승. jewel: 공격자가 crown_jewel 을 1.0 으로 만들면 즉시 패, N턴 버티면 승, 점수 = 버틴 턴×100 − Σ격리비용×100.
- Windows / PowerShell 5.1(`;` 사용), npm 은 `ui/` 에서, 커밋은 저장소 루트에서. LF, UTF-8 no BOM. 커밋 메시지는 한국어 한 줄 + 본문, 끝에 `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
- 개발 서버가 http://localhost:5179/ 에 떠 있으면 그것을 쓴다(새로 띄우지 않는다).

```js
// 격리 자산은 공격자에게 없는 자산이다: 거점도, 경유지도, 표적도 아니다 (ADR-0026).
// state 값은 그대로 두고(임무 수치는 compromise=1 로 따로 들어간다) 목록만 걸러낸다.
function isoSet(isolated) {
  return new Set(Array.isArray(isolated) ? isolated : [])
}

function reachableFrom(g, state, t, fromId, isolated = []) {
  const iso = isoSet(isolated)
  const snap = runChain(g, state, { t, causes: 'all' })
  const links = g.links || []
  const assets = g.assets || []
  if (!links.length) return assets.map((a) => a.id).filter((id) => id !== fromId && !iso.has(id))

  const out = []
  for (const a of assets) {
    if (a.id === fromId) continue
    if (snap.asset_outage[a.id] || iso.has(a.id)) continue
    if (isReachable(g, snap, fromId, a.id, iso)) out.push(a.id)
  }
  return out
}

function isReachable(g, snap, from, to, iso = new Set()) {
  if (from === to) return true
  const down = (id) => !!snap.asset_outage[id] || iso.has(id)
  const links = (g.links || []).filter((l) => !snap.link_outage[l.id])
  const transit = {}
  for (const a of g.assets || []) transit[a.id] = a.transit === false ? false : true
  const adj = {}
  for (const a of g.assets || []) adj[a.id] = []
  for (const l of links) {
    if (down(l.a) || down(l.b)) continue
    adj[l.a].push(l.b)
    adj[l.b].push(l.a)
  }
  if ((adj[from] || []).includes(to)) return true
  const seen = new Set([from])
  const stack = (adj[from] || []).filter((m) => transit[m] && !down(m))
  for (const m of stack) seen.add(m)
  while (stack.length) {
    const n = stack.pop()
    if (n === to) return true
    for (const m of adj[n] || []) {
      if (seen.has(m)) continue
      seen.add(m)
      if (m === to) return true
      if (transit[m] && !down(m)) stack.push(m)
    }
  }
  return seen.has(to)
}

export function footholds(state, isolated = []) {
  const iso = isoSet(isolated)
  return Object.keys(state || {}).filter((k) => Number(state[k]) >= FOOTHOLD && !iso.has(k))
}

export function attackerView(g, state, t, opts = {}) {
  const own = footholds(state, opts.isolated)
  const seen = new Set(own)
  for (const f of own) for (const id of reachableFrom(g, state, t, f, opts.isolated)) seen.add(id)
  return { footholds: own, visible: [...seen] }
}

export function legalMoves(g, state, t, opts = {}) {
  const moves = []
  const view = attackerView(g, state, t, opts)
  const lvl = (id) => Number((state || {})[id] || 0)

  if (!view.footholds.length) return moves

  moves.push({ id: 'recon', action: 'recon', target: null, from: null, ...meta('recon') })

  for (const f of view.footholds) {
    if (lvl(f) >= FOOTHOLD && lvl(f) < 1) {
      moves.push({ id: `credential_access:${f}`, action: 'credential_access', target: f, from: f, ...meta('credential_access') })
    }
    if (lvl(f) >= LATERAL_FROM) {
      for (const to of reachableFrom(g, state, t, f, opts.isolated)) {
        if (lvl(to) >= FOOTHOLD) continue
        moves.push({ id: `lateral_move:${f}->${to}`, action: 'lateral_move', from: f, target: to, ...meta('lateral_move') })
      }
    }
  }
  for (const id of view.visible) {
    if (lvl(id) >= FOOTHOLD && lvl(id) < 1) {
      moves.push({ id: `escalate:${id}`, action: 'escalate', from: id, target: id, ...meta('escalate') })
    }
    if (lvl(id) >= DENY_FROM) {
      moves.push({ id: `deny:${id}`, action: 'deny', from: id, target: id, ...meta('deny') })
    }
  }
  const seen = new Set()
  return moves.filter((m) => (seen.has(m.id) ? false : (seen.add(m.id), true)))
}
```

```js
import { describe, it, expect } from 'vitest'
import payload from '../../public/data/tacnet-01.replay.json'
import { runStep } from '../engine.js'
import { footholds } from '../attack.js'
import {
  startGame, defaultFoothold, legalFor, isolationCost, defend, pass, attackerTurn,
  evaluate, staffTable, compromiseOf,
} from '../game.js'

const g = payload.graph
const base = { mode: 'hold', turns: 8, t: 150, foothold: { id: 'CO2-VEH', level: 0.8 }, seed: 11, strategy: 'greedy' }

describe('startGame / defaultFoothold', () => {
  it('seeds the attacker with the foothold and starts in the defend phase', () => {
    const G = startGame(g, base)
    expect(G.attacker).toEqual({ 'CO2-VEH': 0.8 })
    expect(G).toMatchObject({ turn: 0, phase: 'defend', isolated: [], history: [], result: null })
    expect(G.score).toEqual({ total: 0, perTurn: [], isolationCost: 0 })
  })
  it('defaultFoothold reads the first compromised asset of the attack timeline', () => {
    expect(defaultFoothold(payload)).toEqual({ id: 'CO2-VEH', level: 0.5 })
    expect(defaultFoothold({ attack: { steps: [] } })).toBe(null)
  })
})

describe('isolation', () => {
  it('compromiseOf merges isolated assets as 1 without touching attacker levels', () => {
    const G = defend(g, startGame(g, base), { type: 'isolate', id: 'RELAY-1' })
    expect(G.attacker).toEqual({ 'CO2-VEH': 0.8 })
    expect(compromiseOf(G)).toEqual({ 'CO2-VEH': 0.8, 'RELAY-1': 1 })
    expect(footholds(G.attacker, G.isolated)).toEqual(['CO2-VEH'])
  })
  it('isolationCost equals the engine what-if delta, priority-weighted', () => {
    const G = startGame(g, base)
    const step = runStep(g, compromiseOf(G), { t: 150, method: 'weighted', candidates: ['TOC-SRV'] })
    let want = 0
    for (const m of g.missions) want += (step.whatif['TOC-SRV'].delta[m.id] || 0) / Math.max(1, m.priority || 1)
    expect(isolationCost(g, G, 'TOC-SRV')).toBeCloseTo(want, 6)
  })
  it('defend moves to the attack phase, records cost, and is ignored outside the defend phase', () => {
    const G1 = defend(g, startGame(g, base), { type: 'isolate', id: 'RELAY-1' })
    expect(G1.phase).toBe('attack')
    expect(G1.pending.defender).toMatchObject({ type: 'isolate', id: 'RELAY-1' })
    const G2 = defend(g, G1, { type: 'isolate', id: 'TOC-SRV' })
    expect(G2).toBe(G1)
    expect(pass(startGame(g, base))).toMatchObject({ phase: 'attack', pending: { defender: null } })
  })
})

describe('turns and reproducibility', () => {
  it('attackerTurn appends history, advances the turn, and returns to defend', () => {
    const G = attackerTurn(g, pass(startGame(g, base)))
    expect(G.turn).toBe(1)
    expect(G.phase).toBe('defend')
    expect(G.history.length).toBe(1)
    expect(G.history[0]).toMatchObject({ turn: 0, defender: null })
    expect(typeof G.history[0].p1).toBe('number')
    expect(G.score.perTurn.length).toBe(1)
  })
  it('the same seed and the same actions give the same history', () => {
    const play = () => {
      let G = startGame(g, base)
      G = attackerTurn(g, pass(G))
      G = attackerTurn(g, defend(g, G, { type: 'isolate', id: 'RELAY-1' }))
      G = attackerTurn(g, pass(G))
      return G
    }
    expect(play().history).toEqual(play().history)
  })
})

describe('evaluate: hold', () => {
  const done = (p1) => ({ ...startGame(g, { ...base, turns: 1 }), turn: 1, history: [{ turn: 0, defender: null, attacker: null, missions: {}, p1, weighted: 0.3 }] })
  it('wins when P1 < 0.5 at the end, loses otherwise, and scores the weighted sum', () => {
    const w = evaluate(g, done(0.2))
    expect(w.result).toMatchObject({ win: true })
    expect(w.phase).toBe('over')
    expect(w.score.total).toBeCloseTo(0.3, 6)
    expect(evaluate(g, done(0.7)).result).toMatchObject({ win: false })
  })
  it('does not end before the turn budget', () => {
    const G = { ...done(0.2), turn: 0 }
    expect(evaluate(g, { ...G, cfg: { ...G.cfg, turns: 3 } }).result).toBe(null)
  })
})

describe('evaluate: jewel', () => {
  it('loses the moment the attacker fully owns a crown jewel, scoring turns*100 - isolation cost*100', () => {
    let G = startGame(g, { ...base, mode: 'jewel', turns: 8 })
    G = { ...G, turn: 3, attacker: { 'CO2-VEH': 0.8, 'TOC-SRV': 1 },
      history: [{ turn: 2, defender: { type: 'isolate', id: 'FDC-SRV', cost: 0.25 }, attacker: null, missions: {}, p1: 1, weighted: 1 }] }
    const r = evaluate(g, G)
    expect(r.result).toMatchObject({ win: false, at: 3 })
    expect(r.result.reason).toContain('TOC-SRV')
    expect(r.score.total).toBe(3 * 100 - 25)
  })
  it('an isolated crown jewel is not a loss', () => {
    let G = startGame(g, { ...base, mode: 'jewel', turns: 2 })
    G = { ...G, turn: 2, isolated: ['TOC-SRV'], history: [] }
    expect(evaluate(g, G).result).toMatchObject({ win: true })
  })
})

describe('staffTable', () => {
  it('ranks by net (gainBlocked - cost), then blocks, and only lists non-isolated assets', () => {
    const G = defend(g, startGame(g, base), { type: 'isolate', id: 'FDC-TERM' })
    const rows = staffTable(g, { ...G, phase: 'defend' })
    expect(rows.some((r) => r.id === 'FDC-TERM')).toBe(false)
```

```js
// Wargame core (ADR-0026). Pure functions over the attacker engine
// (attack.js) and the mission engine (engine.js): a game is a value, every
// action returns a new one, and the same seed with the same actions gives the
// same history. Nothing here touches the DOM or the network - the LLM
// attacker's pick is handed in as a constant chooser by the caller.
//
// Isolation is the defender's one move. It means two different things on
// purpose: to the mission engine the asset is down (compromise 1, the same
// arithmetic the 대응 tab uses), to the attacker the asset does not exist
// (attack.js `isolated`). Isolating a fully compromised asset costs the
// mission nothing and stops the spread - that choice is the game.

import { legalMoves, scoreMoves, playTurn, footholds, greedyChooser, randomChooser } from './attack.js'
import { runChain } from './engine.js'

const DEFAULTS = { mode: 'hold', turns: 8, t: 0, foothold: null, seed: 20260906, strategy: 'greedy', method: 'weighted' }

export function compromiseOf(G) {
  const s = { ...(G.attacker || {}) }
  for (const id of G.isolated || []) s[id] = 1
  return s
}

function missionsAt(g, G) {
  return runChain(g, compromiseOf(G), { t: G.cfg.t, method: G.cfg.method, causes: 'all' }).mission
}

// priority-weighted sum, the same weight scoreMoves uses for the attacker
export function weightedOf(g, missions) {
  let s = 0
  for (const m of g.missions || []) s += (missions[m.id] || 0) / Math.max(1, Number(m.priority) || 1)
  return Number(s.toFixed(6))
}

function p1Of(g, missions) {
  const m = [...(g.missions || [])].sort((a, b) => (a.priority || 9) - (b.priority || 9))[0]
  return m ? Number(missions[m.id] || 0) : 0
}

// The first asset the authored attack timeline compromises, at its first level.
export function defaultFoothold(payload) {
  for (const st of payload?.attack?.steps || []) {
    const ids = Object.keys(st.state || {}).filter((k) => Number(st.state[k]) > 0)
    if (ids.length) return { id: ids[0], level: Number(st.state[ids[0]]) }
  }
  return null
}

export function startGame(g, cfg = {}) {
  const c = { ...DEFAULTS, ...cfg }
  const attacker = c.foothold && c.foothold.id ? { [c.foothold.id]: Number(c.foothold.level) || 0.5 } : {}
  return {
    cfg: c, turn: 0, phase: 'defend', attacker, isolated: [], pending: null,
    history: [], score: { total: 0, perTurn: [], isolationCost: 0 }, result: null,
  }
}

export function legalFor(g, G) {
  const legal = legalMoves(g, G.attacker, G.cfg.t, { isolated: G.isolated })
  return scoreMoves(g, compromiseOf(G), G.cfg.t, legal, G.cfg.method)
    .sort((a, b) => (b.gain - a.gain) || (b.p - a.p) || a.id.localeCompare(b.id))
}

export function isolationCost(g, G, id) {
  const before = weightedOf(g, missionsAt(g, G))
  const after = weightedOf(g, missionsAt(g, { ...G, isolated: [...G.isolated, id] }))
  return Number((after - before).toFixed(6))
}

export function defend(g, G, act) {
  if (!G || G.phase !== 'defend' || G.result) return G
  if (!act || act.type !== 'isolate' || !act.id) return G
  if (G.isolated.includes(act.id)) return G
  if (!(g.assets || []).some((a) => a.id === act.id)) return G
  const cost = isolationCost(g, G, act.id)
  return { ...G, isolated: [...G.isolated, act.id], phase: 'attack', pending: { defender: { type: 'isolate', id: act.id, cost } } }
}

export function pass(G) {
  if (!G || G.phase !== 'defend' || G.result) return G
  return { ...G, phase: 'attack', pending: { defender: null } }
}

export function chooserFor(G) {
  if (G.cfg.strategy === 'random') return randomChooser(G.cfg.seed + G.turn)
  return greedyChooser
}

export function attackerTurn(g, G, chooser) {
  if (!G || G.phase !== 'attack' || G.result) return G
  const r = playTurn(g, G.attacker, G.cfg.t, {
    method: G.cfg.method, seed: G.cfg.seed, turn: G.turn,
    chooser: chooser || chooserFor(G), isolated: G.isolated,
  })
  const attacker = r.move ? r.state : G.attacker
  const next = { ...G, attacker, pending: null }
  const missions = missionsAt(g, next)
  const rec = {
    turn: G.turn,
    defender: (G.pending && G.pending.defender) || null,
    attacker: r.move ? {
      move: { id: r.move.id, action: r.move.action, label: r.move.label, from: r.move.from, target: r.move.target, technique: r.move.technique, gain: r.move.gain, p: r.move.p },
      success: r.success, roll: r.roll, rationale: r.rationale || null,
    } : null,
    reason: r.move ? null : (r.reason || 'no legal move'),
    missions,
    p1: p1Of(g, missions),
    weighted: weightedOf(g, missions),
  }
  next.history = [...G.history, rec]
  next.turn = G.turn + 1
  next.phase = 'defend'
  return evaluate(g, next)
}

export function evaluate(g, G) {
  const jewels = g.crown_jewels || []
  let result = G.result || null
  if (!result && G.cfg.mode === 'jewel') {
    const lost = jewels.find((id) => Number((G.attacker || {})[id] || 0) >= 1)
    if (lost) result = { win: false, reason: `${lost} 장악`, at: G.turn }
  }
  if (!result && G.turn >= G.cfg.turns) {
    if (G.cfg.mode === 'hold') {
      const last = G.history[G.history.length - 1]
      const p1 = last ? Number(last.p1) : 0
      result = { win: p1 < 0.5, reason: p1 < 0.5 ? 'P1 임무 저하도 50% 미만 유지' : 'P1 임무 저하도 50% 이상', at: G.turn }
    } else {
      result = { win: true, reason: `${G.cfg.turns}턴 동안 보석 방어`, at: G.turn }
    }
  }
  const perTurn = G.history.map((h) => Number(h.weighted) || 0)
  const isolationCostSum = Number(G.history.reduce((s, h) => s + ((h.defender && h.defender.cost) || 0), 0).toFixed(6))
  const total = G.cfg.mode === 'hold'
    ? Number(perTurn.reduce((a, b) => a + b, 0).toFixed(6))
    : Math.round((result ? result.at : G.turn) * 100 - isolationCostSum * 100)
  return { ...G, score: { total, perTurn, isolationCost: isolationCostSum }, result, phase: result ? 'over' : G.phase }
}

// The staff's ranking. Rules only: what an isolation costs the mission, how
// many of the attacker's current moves it removes, and the biggest gain among
// those. A model may narrate this table; it never reorders it (ADR-0003).
export function staffTable(g, G) {
  const legal = legalFor(g, G)
  const rows = (g.assets || []).map((a) => a.id).filter((id) => !G.isolated.includes(id)).map((id) => {
    const cost = isolationCost(g, G, id)
    const after = new Set(legalMoves(g, G.attacker, G.cfg.t, { isolated: [...G.isolated, id] }).map((m) => m.id))
    const removed = legal.filter((m) => !after.has(m.id))
    const gainBlocked = removed.reduce((mx, m) => Math.max(mx, m.gain), 0)
    return { id, cost, blocks: removed.length, gainBlocked: Number(gainBlocked.toFixed(6)), net: Number((gainBlocked - cost).toFixed(6)) }
  })
  rows.sort((a, b) => (b.net - a.net) || (b.blocks - a.blocks) || a.id.localeCompare(b.id))
  return rows.map((r, i) => ({ ...r, rank: i + 1 }))
}
```

```js
import { legalFor } from './game.js'
import { footholds } from './attack.js'

// What the pictures draw during a wargame. Candidates are the attacker's top
// six legal moves as the engine scores them - read from the same list the
// panel shows, never inferred. Lateral moves become edges, self-targeted
// moves (escalate/deny/credential) become node threats.
export function gameOverlay(g, game) {
  if (!game) return null
  const top = legalFor(g, game).filter((m) => m.target).slice(0, 6)
  const candidates = [], nodeThreats = []
  top.forEach((m, i) => {
    if (m.from && m.from !== m.target) candidates.push({ from: m.from, to: m.target, gain: m.gain, rank: i + 1, label: m.label })
    else nodeThreats.push({ id: m.target, gain: m.gain, rank: i + 1, label: m.label })
  })
  const rec = game.history[game.history.length - 1]
  const last = rec && rec.attacker && rec.attacker.move.target
    ? { from: rec.attacker.move.from, to: rec.attacker.move.target, success: rec.attacker.success, turn: rec.turn }
    : null
  return { candidates, nodeThreats, last, isolated: game.isolated.slice(), footholds: footholds(game.attacker, game.isolated), turn: game.turn }
}
```

```jsx
// Split on sentence ends, keep the [F#] chips, mark the uncited (ADR-0009).
function CitedText({ text, facts, onToast }) {
  const map = new Map(facts.map((f) => [f.id, f.text]))
  const sentences = String(text).split(/(?<=[.!?。])\s+|(?<=\])\s+/).filter((x) => x.trim())
  return sentences.map((raw, i) => {
    const cites = [...raw.matchAll(/\[(F\d+)\]/g)].map((m) => m[1])
    const body = raw.replace(/\[(F\d+)\]/g, '').replace(/\s+([.,])/g, '$1').trim()
    return (
      <p className="brief-s" key={i}>{body}{' '}
        {cites.map((c) => (
          <button key={c} type="button" className={`cite-chip${map.has(c) ? '' : ' is-bad'}`} title={map.get(c) || '근거 없음'} onClick={() => onToast(`${c} — ${map.get(c) || '근거 없음'}`)}>{c}</button>
        ))}
        {cites.length === 0 && <span className="unverified">미검증</span>}
      </p>
    )
  })
}

function StaffCard({ graph, game, rows, p1, llmOk, onIsolate, onToast }) {

  useEffect(() => { setNarr(null) }, [game.turn, game.isolated.length])
  const ask = async () => {
    setBusy(true)
    try {

  const llmOk = !!(probe && probe.ok)

    const first = [...(graph.missions || [])].sort((a, b) => (a.priority || 9) - (b.priority || 9))[0]
    return first ? Number(m[first.id] || 0) : 0

  const isolate = (id) => { if (!id) return; onGame(defend(graph, game, { type: 'isolate', id })); setIso('') }
  const skip = () => onGame(pass(game))
  const attack = async () => {
    if (!game || game.phase !== 'attack' || busy) return
    setBusy(true)

      let chooser

    </div>
  )
}
```

```markdown
# ADR-0026. 교전 규칙 - 턴, 승패, 점수, 격리의 의미, 참모의 권한

**상태**: 채택 (2026-09-20). ADR-0019(적대 시뮬레이션)를 대체하지 않는다.

## 맥락

ADR-0019 는 공격자 엔진(합법수 열거·시드 판정·greedy/random/LLM 선택)을 정했고 그것을
화면에 올렸다(docs/13 §10). 그 화면은 게임이 아니었다: 방어 행동이 격리 하나, 승패·턴·점수
없음, 그래프·지도에 아무것도 안 그림. 그리고 격리가 `state[id]=1` 로 들어가 `footholds()`
가 격리 자산을 공격자 거점으로 셌다. 방어 행동이 공격자를 도왔다.

## 결정

1. **턴 구조.** 방어(격리 1회 또는 생략) → 공격(엔진이 수를 고르고 판정) → 평가. `turns` 회.
   시작 시 시점 `t`, 초기 거점(자산·수준), 모드, 턴 수, 공격자, 시드를 고른다.
2. **격리의 의미.** 임무 수치에는 `compromise=1`(자산 미가용, 대응 탭과 같은 산식).
   공격자에게는 **없는 자산**(거점·경유·표적 제외, `attack.js` `isolated`). 턴당 1회, 영구.
   침해 1.0 자산을 격리하면 임무 비용 0, 확산 차단 - 이 선택이 게임이다.
3. **모드와 점수.** hold: 점수 = Σ_turns Σ_missions (저하도 × 1/priority), 낮을수록 좋음,
   종료 시 P1 < 0.5 이면 승. jewel: 공격자가 crown_jewel 을 1.0 으로 만들면 즉시 패, N턴
   버티면 승, 점수 = 버틴 턴×100 − Σ격리비용×100. 자기가 격리한 보석은 패가 아니다.
4. **참모.** 순위 = 규칙(`gainBlocked − cost`, 동률은 `blocks`). 모델은 있으면 그 표를 2~3
   문장으로 **읽어 주며** 문장마다 [F#] 인용(ADR-0009). 모델은 순위를 바꾸지도, 행동을
   고르지도, 실행하지도 않는다(ADR-0003/0004). 참모 문장은 상태에 남지 않는다.
5. **재현성.** 같은 그래프·설정·행동 열이면 history 가 같다. 시드는 화면에 보인다.
6. **그림.** 후보수는 빨강 저불투명도 점선(공격자의 수), 판정은 0.8초 번쩍임, 격리는 무채
   이중선. 빨강=공격 규칙(ADR-0012)은 그대로다.

## 하지 않는 것

격리 외 방어 행동, 실시간 자동 진행, 엔진의 격리 원인 분해(원인 색 8종·parity 유지),
LLM 이 방어 행동을 고르는 경로.
```
