# AWS-0 정적 사본 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 심사·시연용 공개 사본을 S3 + CloudFront 로 올릴 수 있는 저장소 자산(템플릿·배포 스크립트·문서)을 만들고, 지금 `proxied` 자세를 깨뜨리고 있는 프록시 허용목록 결함을 고친다.

**Architecture:** 정적 번들은 비공개 S3 버킷에 두고 CloudFront OAC 로만 읽는다. 인증은 CloudFront 뷰어 요청 함수(basic auth)에서 한다 - 도메인이 없어 오리진 구간이 http 이므로 비밀번호가 평문으로 흐르면 안 된다. 모델 오리진(`/api/llm/*`)은 **조건부 리소스**로 템플릿에 미리 넣어 두고, GPU 인스턴스가 생기는 AWS-1 에서 파라미터 하나로 켠다. AWS 리소스 생성과 `aws` 명령 실행은 사람이 한다.

**Tech Stack:** CloudFormation(YAML), CloudFront Functions(cloudfront-js-2.0), PowerShell 5.1, AWS CLI v2, cfn-lint(Python 3.12), 기존 게이트 하네스(`scripts/Invoke-Gates.ps1`).

**Spec:** `docs/superpowers/specs/2026-09-23-aws-demo-design.md`

### Task 1: 프록시 허용목록이 실제 클라이언트 경로와 맞게 고친다

지금 결함: 클라이언트는 `${endpoint}/api/chat`(`ui/src/staff-llm.mjs:33`, `ui/src/attack-llm.mjs:213`)과 `${endpoint}/api/tags`(`ui/src/attack-llm.mjs:362`, `ui/src/config.js` 의 `probeLlm`)를 부르는데, 두 배포 예시는 `/api/llm/api/generate` 만 허용한다. `proxied` 자세에서 모든 모델 호출이 403 이다.

**Interfaces:**

- [ ] **Step 1: 실패하는 검사기를 먼저 쓴다**

`scripts/Test-ProxyAllowlist.ps1` (ASCII only). 하는 일: `ui/src/` 의 `.js`/`.mjs` 에서 정규식 `\$\{(?:cfg\.)?endpoint\}(/api/[a-z]+)` 로 클라이언트가 부르는 업스트림 경로를 모으고, 각 경로가 `deploy/nginx.example.conf` 와 `deploy/Caddyfile.example` 양쪽에 `/api/llm<path>` 형태로 나오는지 확인한다. 하나라도 빠지면 그 경로와 파일을 출력하고 exit 1.

```powershell
# Deploy allowlist drift gate. ASCII only in this file.
#
# The client calls Ollama through /api/llm/. The proxy examples allow exactly
# the upstream paths the client uses and refuse the rest, because Ollama's API
# is also a model management API. That only holds while the two lists agree.
# They did not: the client moved to /api/chat and the examples still allowed
# /api/generate, so the proxied posture answered 403 to every call.

$ErrorActionPreference = 'Stop'
$root = Split-Path -Parent $PSScriptRoot
$src  = Join-Path $root 'ui\src'
$conf = @(
  (Join-Path $root 'deploy\nginx.example.conf'),
  (Join-Path $root 'deploy\Caddyfile.example')
)

$wanted = New-Object System.Collections.Generic.HashSet[string]
Get-ChildItem -Path $src -Recurse -Include *.js, *.mjs | ForEach-Object {
  $text = Get-Content -Raw -Encoding utf8 $_.FullName
  foreach ($m in [regex]::Matches($text, '\$\{(?:cfg\.)?endpoint\}(/api/[a-z]+)')) {
    [void]$wanted.Add($m.Groups[1].Value)
  }
}

if ($wanted.Count -eq 0) { Write-Host 'FAIL: no upstream paths found in ui/src'; exit 1 }

$bad = @()
foreach ($file in $conf) {
  $text = Get-Content -Raw -Encoding utf8 $file
  foreach ($path in $wanted) {
    if ($text -notmatch [regex]::Escape("/api/llm$path")) {
      $bad += "$(Split-Path -Leaf $file) is missing /api/llm$path"
    }
  }
}

if ($bad.Count -gt 0) { $bad | ForEach-Object { Write-Host "FAIL: $_" }; exit 1 }
Write-Host "OK: proxy allowlist covers $($wanted.Count) upstream path(s): $($wanted -join ', ')"
exit 0
```

### Task 2: CloudFormation 템플릿 `infra/demo-static.yaml`

**Files:**
- Create: `infra/demo-static.yaml`, `infra/README.md`

**Interfaces:**
- Produces: 스택 출력 `BucketName`, `DistributionId`, `DomainName`. Task 3 의 배포 스크립트가 이 셋을 인자로 받는다.
- Produces: 파라미터 `LlmOriginDomain`(기본 `''`) - AWS-1 이 이 값만 채우면 모델 경로가 켜진다.

- [ ] **Step 1: 템플릿을 쓴다**

파라미터:

| 이름 | 형 | 기본 | 설명 |
|---|---|---|---|
| `BucketName` | String | - | 전역 고유 버킷 이름 |
| `BasicAuthBase64` | String, NoEcho | - | `user:pass` 의 base64. 운영자가 만들어 넣는다 |
| `LlmOriginDomain` | String | `''` | GPU 오리진의 DNS 이름. 빈 값이면 모델 경로를 만들지 않는다 |
| `LlmOriginSecret` | String, NoEcho | `''` | CloudFront 가 오리진에 붙이는 비밀 헤더 값 |

리소스:

- `BundleBucket` (`AWS::S3::Bucket`): `PublicAccessBlockConfiguration` 네 값 전부 true, `OwnershipControls` `BucketOwnerEnforced`.
- `LogBucket` (`AWS::S3::Bucket`): `OwnershipControls` **`BucketOwnerPreferred`**(CloudFront 표준 로그가 ACL 을 쓴다), `LifecycleConfiguration` 규칙 하나 - `Status: Enabled`, `ExpirationInDays: 90`.
- `Oac` (`AWS::CloudFront::OriginAccessControl`): `OriginAccessControlOriginType: s3`, `SigningBehavior: always`, `SigningProtocol: sigv4`.
- `AuthFunction` (`AWS::CloudFront::Function`): `FunctionConfig.Runtime: cloudfront-js-2.0`, `AutoPublish: true`, 코드는 `Fn::Sub` 로 `${BasicAuthBase64}` 를 박는다:

```js
function handler(event) {
  var h = event.request.headers;
  var want = 'Basic ${BasicAuthBase64}';
  if (!h.authorization || h.authorization.value !== want) {
    return {
      statusCode: 401, statusDescription: 'Unauthorized',
      headers: { 'www-authenticate': { value: 'Basic realm="MC-CyCOP demo"' } }
    };
  }
  return event.request;
}
```

- `Distribution` (`AWS::CloudFront::Distribution`):
  - `DefaultRootObject: index.html`, `Enabled: true`, `HttpVersion: http2and3`
  - `Logging`: `Bucket: !GetAtt LogBucket.DomainName`, `Prefix: cf/`
  - `Origins`: S3 오리진(`DomainName: !GetAtt BundleBucket.RegionalDomainName`, `OriginAccessControlId: !GetAtt Oac.Id`, `S3OriginConfig: { OriginAccessIdentity: '' }`). `HasLlm` 조건이면 두 번째 오리진을 덧붙인다 - `!If [HasLlm, [s3오리진, llm오리진], [s3오리진]]` 형태로 **목록 전체**에 `!If` 를 건다.
    LLM 오리진: `Id: llm`, `DomainName: !Ref LlmOriginDomain`, `CustomOriginConfig: { OriginProtocolPolicy: http-only, HTTPPort: 80, OriginReadTimeout: 60 }`, `OriginCustomHeaders: [{ HeaderName: X-Demo-Origin, HeaderValue: !Ref LlmOriginSecret }]`.
  - `DefaultCacheBehavior`: `TargetOriginId: bundle`, `ViewerProtocolPolicy: redirect-to-https`, `AllowedMethods: [GET, HEAD]`, `CachePolicyId: 658327ea-f89d-4fab-a63d-7e88639e58f6`(CachingOptimized), `FunctionAssociations: [{ EventType: viewer-request, FunctionARN: !GetAtt AuthFunction.FunctionMetadata.FunctionARN }]`
  - `CacheBehaviors`: `!If [HasLlm, [ ... ], !Ref AWS::NoValue]` - 경로 `/api/llm/*`, `TargetOriginId: llm`, `ViewerProtocolPolicy: https-only`, `AllowedMethods: [GET, HEAD, OPTIONS, PUT, POST, PATCH, DELETE]`, `CachePolicyId: 4135ea2d-6df8-44a3-9df3-4b5a84be39ad`(CachingDisabled), `OriginRequestPolicyId: 216adef6-5c7f-47e4-b989-5492eb8d9cf2`(AllViewer), 같은 뷰어 함수 연결.
- `BucketPolicy` (`AWS::S3::BucketPolicy`): `Principal: { Service: cloudfront.amazonaws.com }`, `Action: s3:GetObject`, `Resource: !Sub '${BundleBucket.Arn}/*'`, `Condition: { StringEquals: { 'AWS:SourceArn': !Sub 'arn:aws:cloudfront::${AWS::AccountId}:distribution/${Distribution}' } }`.

조건: `HasLlm: !Not [!Equals [!Ref LlmOriginDomain, '']]`.

주의(AWS-1 이 확인할 것): 뷰어 함수를 `/api/llm/*` 행동에도 걸기 때문에 브라우저의 `fetch` 가
basic auth 자격을 같이 보내야 한다. 같은 오리진이면 브라우저가 캐시된 자격을 자동으로 붙이지만,
사람이 아직 인증하지 않은 상태에서 `probeLlm()` 이 먼저 돌면 401 을 받고 "모델 없음"으로 읽힌다.
정적 페이지가 먼저 인증을 통과한 뒤에 프로브가 도는 순서라 실제로는 문제가 없어야 하고,
AWS-1 의 확인 목록 5번이 이것을 실물로 확인한다.

출력: `BucketName`(!Ref BundleBucket), `DistributionId`(!Ref Distribution), `DomainName`(!GetAtt Distribution.DomainName).
