# 상황도 UI 2차 개편 - 실지형 지리 뷰 + 관제 콘솔 밀도 (설계)

작성 2026-09-19. 승인됨(대화). 구현 계획은 별도 문서.

## 0. 왜

D4D 쇼케이스 49개(`https://d4d.tech/api/showcase`)와 그중 깃허브 33개를 조사했다.
C2·COP 계열 20개의 화면과 우리 화면을 나란히 놓고 본 차이:

| | 쇼케이스 다수 | 우리 (2026-09-14) |
|---|---|---|
| 지리 바탕 | 위성영상·3D 지구본(Cesium 3팀), 벡터 다크맵(MapLibre 4팀, Leaflet 6팀) | 손으로 그린 등고선 + 격자. "가상 좌표" 고지 |
| 상단 KPI 띠 | 큰 숫자 5~6개 + 링 게이지 + 상태 필 | 없음 |
| 이벤트 스트림 | 타임스탬프 달린 로그가 계속 흐름 | 없음 (시간축 마커 hover 만) |
| 캔버스 밀도 | 그래프가 화면을 채우고 글로우·애니메이션 | dagre 그래프가 캔버스 1/4 |
| AI 패널 | 인용 달린 응답이 항상 우측에 | 브리핑이 탭 안에 숨음 |
| 재생 컨트롤 | 재생·배속·리플레이 버튼이 큼 | ▶ 하나 |

데모가 1순위다(ADR-0014). 이 차이를 좁힌다. 단 "있어보이게" 하려고 확정 결정을
조용히 깨지 않는다 - 깨는 것은 ADR-0025 에 적고 깬다.

## 1. 범위와 불변 조건

**유지 (건드리지 않는다)**
- 엔진·전파 함수·`replay.json` 계약(`Export-ReplayData.ps1` 출력 형식)
- 의존 그래프가 기본 뷰(ADR-0001). 지리는 토글 가능한 부가 뷰
- 엔진은 geo 를 읽지 않는다. `Test-GeoInvariance.ps1` 이 그대로 통과해야 한다
- 빨강은 공격 전용(ADR-0012). 저하도는 휘도(ADR-0024)
- 자동 실행 경로 없음(ADR-0004). 인용 없는 LLM 응답은 "미검증"(ADR-0009)
- Cytoscape.js 그래프 뷰, Vite 정적 번들, 서버 없음(ADR-0018)
- defnet-01 의 지리(영내 배치도, docs/17 §10)

**바꾼다**
- (a) tacnet-01 지리 뷰 엔진 → MapLibre GL JS
- (b) tacnet-01 좌표를 강원 인제 KCTC 일대 실지형에 재저작
- (c) UI 셸 밀도 - KPI 띠, 이벤트 스트림, 재생 컨트롤, 브리핑 상시 노출
- (d) 색 바탕을 저채도 네이비-블랙으로

**ADR-0025 신설** - 한 문서에 세 가지를 기록한다.
1. 지리 뷰에 실지형·온라인 타일을 허용한다. docs/17 §4.1 배경지도 정책을 폐기하고,
   ADR-0018 의 "CDN 미의존"에 **지도 타일만** 예외를 둔다. 타일이 안 오면 지도는 빈
   바탕 + 오버레이로 동작하고 나머지 화면은 영향이 없어야 한다.
2. 안전성 논거를 교체한다. "가상 좌표"에서 **"공개된 훈련장 지형 위의 가상 훈련
   시나리오 - 실제 부대 배치·실제 편성 미참조 - 화면 워터마크 상시"** 로.
3. ADR-0024 색 규칙 소폭 개정(5절).

## 2. 지리 뷰 (MapLibre GL)

### 2.1 분기 규칙

`graph.geo.georef` 가 **있으면** MapLibre 패널, **없으면** 기존 `geo.js` 로컬 평면
렌더러. 조건은 이 하나뿐이다. tacnet-01 은 georef 가 있으니 MapLibre, defnet-01 은
없으니(docs/17 §10 의 결정) 기존 렌더러. `geo.js`·`terrain.js` 는 삭제하지 않는다.
`positionAt()` 은 두 렌더러가 공유한다.

### 2.2 타일 (전부 키 없음, 인터넷 전제)

| 역할 | 소스 | 비고 |
|---|---|---|
| 바탕(기본) | OpenFreeMap `dark` 벡터 스타일 | 한국어 라벨 유무는 구현 중 확인. 없으면 `name` 그대로 |
| 위성 | ESRI World Imagery 래스터 | 출처 표기 필수 |
| 지형 | AWS Terrain Tiles (Terrarium PNG) raster-dem | 3D 지형 + 음영기복 둘 다 이 소스 |

툴바: 바탕 세그먼트(다크 / 위성 / 지형), 2D/3D 토글 유지. 3D 는 pitch 60, 지형 과장
1.5. 출처 표기는 MapLibre 기본 attribution 컨트롤에 세 소스 전부.

### 2.3 오버레이 (step 마다 GeoJSON 소스 갱신)

| 레이어 | 내용 | 색 규칙 |
|---|---|---|
| 자산 마커 | milsymbol SIDC → 이미지, `symbol` 레이어. 클릭 = 선택 | 침해는 빨강 테두리 + 펄스, 단절은 원인색 테두리 |
| 링크 | `line`. 단절 시 원인색 파선, 정상은 무채 실선 | 원인색 8종만 |
| 기동 궤적 | 현재 t 까지 지나온 구간을 가는 선으로 | 무채 |
| 공격 경로 | 홉 순서대로 호(arc). 파선 오프셋 애니메이션 | 빨강, 화면 유일 |
| what-if | 선택 자산 격리 시 영향 받는 자산에 흰 외곽 링 | 무채 |
| AO 경계·격자 | 24×18 km 사각형 + 2 km 격자 + MGRS 라벨(축척 연동, bunkr `grid.ts` 방식) | 무채 |
| 워터마크 | 좌하단 "가상 훈련 시나리오 · 실제 부대 배치 아님" | 항상. 끌 수 없다 |

선택 상태는 그래프 뷰와 같은 `selected` 를 쓴다. 지도에서 고르면 그래프에서도 고른 것이다.

### 2.4 하지 않는 것

DEM 으로 가시선을 **계산하지 않는다.** 단절 원인은 저작값이다(ADR-0003 경계).
대신 `scripts/check_geo_terrain.py` 가 `cause: terrain` 링크의 양 끝 사이 고도 단면을
**보고만** 한다. 게이트가 아니고 exit 0 이다. 재저작한 위치가 서사와 맞는지 사람이
읽는 용도다.

## 3. 좌표 재저작 (tacnet-01)

- 정본은 여전히 TACGRID-01 로컬 평면(m). 자산에 위경도를 따로 넣지 않는다.
- `georef.anchor` 를 인제로 옮긴다. SW 모서리 약 **38.02 N, 128.08 E** (구현 중 DEM 을
  보고 ±0.03° 조정 가능). 24×18 km 가 인제읍·원통리·소양호 북단을 덮는다.
  변환 공식·`approximation_error_m`·MGRS GZD(52S) 는 동일하다.
- 자산 13개의 x,y 를 실지형에 맞게 다시 놓는다. 기준:
  - RELAY-1 은 실제 능선 위
  - 대대 지휘소(BN-SRV·BN-CP·SAT-TERM) 이동 목적지는 실제 고지
  - FO-TAB 의 255~275 분 구간은 실제 계곡 바닥
  - 여단 TOC 는 저지대 개활지, 포병 FDC 는 중간 고도
- z 는 DEM(Terrarium 타일) 에서 샘플해 기록한다. `geo.source` 를 `"asset-register"` 에서
  `"authored-on-dem"` 으로, 루트에 `dem_source: "aws-terrain-tiles"` 를 적는다.
- **outage 의 from/to/cause 는 바꾸지 않는다.** 따라서 엔진 결과, docs/11 실측표,
  `replay.json` 의 저하도 값은 전부 불변이어야 한다. `Test-Ontology.ps1` 과 export 재실행
  후 저하도 열이 그대로인지 diff 로 확인한다.
- `geo.terrain` 블록(창작 능선·계곡·지형면 파라미터)은 **제거**한다. 실지형이 그 자리를
  대신한다. `geo.safety` 는 1절 ADR-0025 ②의 논거로 재작성한다.

## 4. UI 셸

### 4.1 상단 KPI 띠 (Topbar 확장)

왼쪽부터: 로고 · 시나리오 셀렉터 · 모드(관측/편집/교전) · **KPI 5칸** · 시계 · `?`.

| KPI | 값 | 출처 |
|---|---|---|
| 임무 저하도 P1 | 큰 숫자 + 링 게이지 | `step.mission` |
| 임무 저하도 P2 | 같음 | `step.mission` |
| 침해 자산 | n / 전체 | `step.compromise` |
| 단절 링크 | n, 원인별 점 | `step.link_outage` |
| 상황 등급 | 필 4단계 | 저하도 최대값의 밴드(0 / <30 / <70 / ≥70). 결정론 규칙. 교리 용어(CPCON 등) 안 쓴다 |

시계는 24px 모노스페이스, 옆에 `+분` 과 현재 step 라벨.

### 4.2 그래프

- fit 패딩 축소, 노드 크기 확대. 그래프가 캔버스를 채운다.
- 침해 노드에 원인색 underlay(Cytoscape `underlay-*`) 글로우.
- 공격 경로 엣지에 `line-dash-offset` 애니메이션(흐르는 파선). 빨강.

### 4.3 우측 레일 (위에서 아래)

1. 임무 카드 2장 (지금과 같되 여백 축소)
2. 탭: 단절 / 대응 / 선택 (브리핑 탭은 빠진다 - 3으로)
3. **브리핑 카드(상시)**: 마지막 브리핑 첫 문단 + "인용 n건" 또는 "미검증" 배지 + 펼치기.
   브리핑이 없는 step 은 "이 시점 브리핑 없음".
4. **이벤트 스트림**: replay `steps` 에서 결정론으로 파생. 행 종류:
   - 공격 홉 (`step.gt`, `compromise` 변화) - 빨강 점
   - 링크·자산 단절 시작/복구 (`link_outage`/`asset_outage` 변화) - 원인색 점
   - 단계 전환 (`active_phases` 변화) - 무채
   - 지휘소·차량 이동 시작/도착 (`geo.segments` mode 변화) - 무채
   타임스탬프 `HH:MM`, 현재 t 행 하이라이트 + 자동 스크롤, 클릭 = 그 step 으로 이동.
   파생 함수는 `derive.js` 의 순수 함수 `eventRows(payload)` 로 두고 테스트한다.

### 4.4 시간축

큰 재생 버튼(36px), ◀ ▶ 스텝, 배속 세그먼트 1× / 4× / 16×, 오른쪽에 큰 시각.
단계 밴드·단절 바·공격 마커는 지금 것 유지.

### 4.5 서체

본문 IBM Plex Sans KR 유지. 수치·시계·로그·좌표는 **IBM Plex Mono**. 둘 다
`@fontsource/*` 로 번들에 넣는다(온프렘, ADR-0007). CDN 폰트 링크 없음.

## 7. 하지 않는 것

Cesium. DEM 기반 가시선이 판단에 들어가는 경로. defnet-01 지리 변경. LLM 역할 확장.
오프라인 타일 패키징(PMTiles) - 인터넷 전제로 결정됐고, 필요해지면 소스 하나 바꾸는 일이다.
사이드바 접기·다국어·모바일.

## 8. 순서

ADR·데이터(3절) → 지리 엔진(2절) → 셸(4절) → 색(5절) → 검증·문서(6절).
데이터를 먼저 하는 이유: 지리 엔진은 새 앵커 위에서만 확인할 수 있고, 좌표 재저작이
엔진 결과를 안 바꾼다는 것을 가장 먼저 못 박아야 나머지가 안전하다.
