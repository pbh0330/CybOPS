### 취득 장벽 (2026-09-05 확인)

- **LANL**: 직접 다운로드 URL이 없다. `csr.lanl.gov/data/cyber1/`에서 **이메일과 사용 목적을
  폼으로 제출**해야 접근 권한이 나온다. 자동화 불가 — 사용자가 직접 신청해야 한다.
  대신 **CC0(퍼블릭 도메인)**이라 재배포 제약이 없다. 논문 부록 활용 여지가 가장 크다.
- **OpTC**: GitHub 저장소는 문서만 있고 실데이터는 **Google Drive 폴더** 호스팅이다
  (약 1TB). curl로 직접 못 받는다. `gdown` 등 별도 도구가 필요하고, 전량 취득은 하지 않는다.
- **AIT**: 유일하게 즉시 자동 다운로드가 되는 데이터셋. 테스트베드 단위 분할이라
  부분 취득도 깔끔하다. **파이프라인 개발 1순위인 이유가 여기서 한 번 더 확인된다.**

## 1. L1 텔레메트리 — 주력

### DARPA OpTC (Operationally Transparent Cyber)

가장 상세한 호스트 기반 공개 데이터셋. 다만 **가장 크므로 마지막에 받는다.**

- Windows 호스트 1,000대 규모. 앞 4일은 정상 활동만, 뒤 3일에 레드팀이 초기 침해 → 내부
  정찰 → C2 → 지속성 확보 → 흔적 삭제까지 APT 전 수명주기 수행. 그라운드트루스 제공.
- 규모: 호스트 이벤트 약 87억 건, Zeek 플로우 약 5.3억 건.
- **군 연계성**: USTRANSCOM 합동배치분배체계(JDDE) 요구에서 식별된 사이버 방어 역량 공백을
  다루기 위한 확장성 검증이었고, 평가는 National Cyber Range에서 수행. 군용 상황도 과제의
  정당화 근거로 인용 가치가 높다.
- 배포 경로: `github.com/FiveDirections/OpTC-data` (공개). IEEE DataPort 경로는 구독 필요.
- **부분 취득 전략**: eCAR 이벤트는 일자·호스트 단위로 분할되어 있다. 레드팀 활동 3일 구간과
  그라운드트루스에 등장하는 호스트 위주로 받는다. 전체를 받지 않는다.

### LANL 데이터셋

실제 국립연구소 운영망 기반이라 정상 트래픽의 결이 인공적이지 않다는 점이 강점.

- **Comprehensive Multi-Source Cyber-Security Events**: 58일간 인증·프로세스·DNS·플로우·
  레드팀 5개 소스. 약 12GB 압축, 총 16억 4천만여 건, 사용자 12,425명, 컴퓨터 17,684대.
- **Unified Host and Network Dataset**: 약 90일치 호스트·네트워크 이벤트.
- 포맷이 단순 CSV라 파이프라인 부담이 낮다. 압축 대비 규모가 커서 **불균형 실험용으로
  비용 대비 효율이 가장 좋다.**

### AIT Log Data Set v2.0 — 재생성 가능성이 핵심 가치

- 8개 테스트베드 각각이 메일서버, 파일공유, WordPress, VPN, 방화벽을 갖춘 소규모 기업망을
  모사. 전 호스트에서 Apache·인증·DNS·VPN·감사·Suricata 로그와 패킷 캡처 수집. 별도
  그라운드트루스 파일로 공격 관련 이벤트 라벨링.
- **모델 기반 테스트베드 자동 생성**을 써서 파라미터를 바꿔 임의 개수의 데이터셋을 생성하고
  자동 라벨링할 수 있다. 테스트베드 구축 코드가 오픈소스로 공개되어 있다.
- **이것이 군 환경 갭을 메우는 열쇠다.** 토폴로지와 서비스 구성을 국방망 형태로 바꿔
  자체 재생성이 가능하다. 원본을 지운 뒤에도 생성기만 있으면 다시 만들 수 있다는 점에서
  수명주기 정책과도 궁합이 좋다.
- 배포: Zenodo (DOI 10.5281/zenodo.5789064, 2022-02-24). 라이선스 **CC BY-NC-SA 4.0**
  (저작자표시-비영리-동일조건변경허락). 비영리 조건이 있으므로 과제 성격에 따라 확인 필요.
- 테스트베드 단위 부분 다운로드 가능. 전체 130.6GB(압축) / 206GB(해제).

### DARPA Transparent Computing (TC)

- CADETS, THEIA, TRACE, FiveDirections 등 서브셋. 각 캠페인에 **MITRE ATT&CK 단계와 정렬된
  그라운드트루스 매니페스트**가 포함되어 기법 단위 라벨링이 가능하다.
- 시나리오: PowerShell Empire 기반 측면이동, Netcat/RDP 유출, 소프트웨어 업데이트
  트로이목마 등 3종 다단계 킬체인.
- 서브셋 단위로 받는다.

### 보조

- **Security Datasets (구 Mordor)**: 공격 기법별 에뮬레이션 로그. 소용량이라 상시 보관 가능.
  ATT&CK 기법 단위 스모크 테스트 입력으로 유용하다.

## 2. L3 시뮬레이터 — 국방 오픈소스

이 부분이 가장 좋은 소식이다. 영국 Dstl의 자율 회복탄력적 사이버 방어(ARCD) 프로그램
산출물들이 공개되어 있어, **국방 프로그램 산출물이라는 점 자체가 과제 정당화 근거가 된다.**

| 도구 | 성격 | 비고 |
|---|---|---|
| **PrimAITE** | Dstl ARCD 다년도 프로그램의 훈련 환경 | QinetiQ가 정부·기관 협력과 커뮤니티 기여 확대를 위해 공개 배포 |
| **Yawning Titan** | 그래프 기반 추상 시뮬레이션 | 확률적 레드 에이전트 대응 방어 에이전트 |
| **CybORG / CAGE 챌린지** | 턴 기반 멀티에이전트 RL 환경 | AWS 인프라 위 네트워크 에뮬레이션 지원 → 시뮬-실환경 괴리 축소 |
| **CybORG++** | CAGE 2 버그 수정 + 경량판 MiniCAGE | 재현성 개선 |
| **Cyberwheel** | 시뮬레이터 + 에뮬레이터 동시 제공 | CAGE 2의 6가지 한계 지적: 토폴로지 구성 제약, 부실한 레드 에이전트 행동, 에뮬레이션 부재, **시각화 도구 부재** 등 |

**Cyberwheel이 지적한 "시각화 도구 부재"가 이 과제의 빈칸이다.** 시뮬레이터가 뱉는 상태
궤적을 상황도 입력으로 물리면 M&S형 지도가 그대로 성립한다.

이들은 코드라 용량 부담이 거의 없다. 수명주기 정책의 PURGE 대상이 아니다.

## 3. 반드시 미리 알아야 할 함정

### 3.1 극단적 클래스 불균형

| 데이터셋 | 악성 비율 |
|---|---|
| LANL | 전체 이벤트 중 0.0000713% |
| DARPA TC 평가 구간 | 약 0.0016% |
| OpTC 공격 흔적 상위 3개 호스트 | 악성 노드 0.024% |

**accuracy로 평가하면 무의미한 숫자가 나온다.** SOC 우선순위 결정의 낮은 precision 문제와
겹쳐 이중으로 위험하다. → ADR-0008, `04-evaluation.md`.

### 3.2 라벨 편향과 커버리지 한계

- **UWF-ZeekData22**: ATT&CK 라벨이 있으나 정찰 단계가 99.97%를 차지하고 네트워크 전용.
- **CICIDS, UNSW-NB15, CTU-13**: 네트워크 트래픽만. 호스트·브라우저 활동 없음.
- 시스템·네트워크·브라우저 세 소스를 항목별 ATT&CK 기법 라벨과 함께 결합한 공개 데이터셋은
  **존재하지 않는다**는 것이 최근 연구의 지적이다.

→ 상황도의 커버리지 주장은 **데이터셋이 담고 있는 기법 범위 내로 한정해서** 기술한다.
과장하면 심사에서 깨진다. 논문에는 "본 연구가 검증한 ATT&CK 기법 범위" 표를 명시적으로 넣는다.

### 3.3 L2는 어차피 없다

임무-자산 온톨로지에 해당하는 공개 데이터는 없다. 자체 정의가 정상 경로다.
→ `03-mission-ontology.md`.

## 4. 라이선스와 재배포

취득 시 각 데이터셋의 라이선스를 `MANIFEST.json`의 `license` / `redistributable` 필드에
기록한다. 대체로 **연구 목적 사용은 허용되나 재배포는 제한**된다고 보고 접근한다.
논문 부록에 실을 수 있는 것은 대개 집계 통계와 평가 지표뿐이다.
