## 2. 제약 — 이게 실무적으로 중요하다

Figma MCP의 호출 한도는 플랜·좌석에 따라 갈린다.

| 좌석 | Starter | Professional | Organization | Enterprise |
|---|---|---|---|---|
| View, Collab | **월 20회** | 월 6회 | 월 6회 | 월 6회 |
| Dev, Full | 월 20회 | 일 200회 / 분 10회 | 일 200회 / 분 15회 | 일 600회 / 분 20회 |

교육(Education) 플랜은 Professional의 Dev/Full과 동일하다: **일 200회, 분 10회.**

- 한도는 **Figma에서 데이터를 읽는 도구**에 적용된다.
- 쓰기 계열 일부는 한도 면제다: `create_new_file`, `add_code_connect_map`, `whoami`.
- **현재 상태(Starter + View)는 월 20회.** 디자인을 읽어와 코드로 옮기는 반복 작업에는
  현실적으로 부족하다. 화면 하나를 제대로 뜯어보는 데만 몇 회가 들어간다.
- 추가로, View 좌석은 Figma 제품 자체에서 편집 권한이 없다. MCP로 파일에 쓰는 작업이
  좌석 권한에 막힐 수 있다.

## 3. 권장 조치

**아주대 이메일(`@ajou.ac.kr`)로 Figma Education 플랜을 신청한다.** 무료이고, 한도가

## 4. 분업 원칙 — 무엇을 Figma에서, 무엇을 코드에서

| 작업 | 도구 | 이유 |
|---|---|---|
| 상황도 화면 구조·레이아웃 탐색 | **Figma** | 시각적 반복이 빠르다 |
| 심볼 체계·색상 등급 정의 (정상/의심/침해/격리) | **Figma** | 디자인 시스템으로 관리 |
| MIL-STD-2525 준용 심볼 매핑 (준용 시) | **Figma** | 심볼 라이브러리 구성 |
| 임무 그래프 렌더링 프로토타입 | **코드** | 실제 데이터·성능이 관건. Figma로 검증 불가 |
| 인터랙션(줌, 필터, 시간축 스크럽) | **코드** | 노드 수천 개 규모 성능이 설계를 좌우 |
| 근거 인용 패널, LLM 스트리밍 패널 | **코드** | 동적 콘텐츠 |

핵심: **정적인 것은 Figma, 데이터가 붙는 것은 코드.** 이 과제의 UI는 후자가 대부분이다.
그래프 레이아웃이 수천 노드에서 읽히는지는 Figma에서 알 수 없다.

## 5. 호출 절약 규칙

한도가 월 20회인 동안:

1. `get_design_context`를 프레임 단위로 좁혀서 호출한다. 파일 전체를 읽지 않는다.
2. 한 번 읽은 결과는 `docs/design/` 아래에 저장해두고 재사용한다. 같은 프레임을 두 번 읽지
   않는다.
3. 화면 확인은 `get_screenshot` 1회로 끝내고, 세부는 저장된 컨텍스트에서 본다.
4. 반복 조정은 코드 프로토타입에서 하고, 확정된 것만 Figma에 반영한다.

## 6. 디자인 산출물 보관

```
docs/design/
├── tokens.md            # 색상 등급, 상태 심볼, 타이포 (Figma에서 추출)
├── screens/<name>.md    # 프레임별 get_design_context 결과 캐시
└── decisions.md         # 디자인 결정 메모 (설계 수준이면 ADR로 승격)
```

## 7. 상황도 UI 설계 시 지켜야 할 제약

디자인 단계에서 이미 확정된 아키텍처 결정이 있다. 디자인이 이를 어기면 구현 불가다.

- **기본 뷰는 임무 그래프.** 지리 지도가 메인 화면이 되는 시안을 만들지 않는다. (ADR-0001)
- **공격 출발지 지도·화살표 화면을 만들지 않는다.** 국가 코드는 참고 표시까지만. (ADR-0002)
- **LLM 패널은 상태 표시와 분리된 영역**에 둔다. 상태 갱신이 LLM 응답을 기다리는 것처럼
  보이는 레이아웃을 만들지 않는다. (ADR-0003)
- **대응 실행 버튼은 반드시 승인 단계를 거치는 흐름**으로 그린다. 원클릭 차단 없음. (ADR-0004)
- **모든 LLM 서술에 근거 인용 표시와 이동 경로**가 있어야 하고, 근거 없는 문장은 "미검증"으로
  시각 구분한다. (ADR-0009)
- 응답성 목표: 단순 조회 0.11초, 복합 조회 1.07초 수준(선행 연구 벤치마크). 이 예산 안에서
  성립하는 인터랙션만 설계한다.
