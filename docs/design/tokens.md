## 핵심 규칙 - 채도는 의미에만 쓴다

크롬(상단바·패널·버튼·탭·시간축)에는 **유채색을 쓰지 않는다.** 화면에서 채도를 가진
것은 원인 색 8종뿐이다. 이 규칙이 ADR-0012(붉은색은 공격 전용)를 색 체계 수준에서
강제한다.

개편 전에는 브랜드 강조색 `#35e0ff` 와 원인 색 `--mobility: #35c8ff` 가 사실상 같은
색이었다. "장식"과 "기동이 원인"이 화면에서 구분되지 않았다.

## 타이포

**IBM Plex Sans KR.** 기존 CSS 스택은 Pretendard 였으나 Figma 에 없다. IBM Plex Sans KR
은 한글을 지원하고, 기술적 성격이 관제 콘솔에 맞고, 오픈소스라 온프렘 자체 호스팅이
된다(ADR-0007). 코드 반영 시 Pretendard 유지 여부는 별도 판단 - 시안은 IBM Plex 기준이다.

| 역할 | 크기 / 굵기 |
|---|---|
| 임무 수치 | 20 SemiBold |
| 시계 | 24 SemiBold |
| 패널 제목 | 13 Medium |
| 본문 | 12-13 Regular |
| 라벨·주석 | 11 Regular |
| 축 눈금 | 10 Regular |

**대문자 트래킹 라벨을 쓰지 않는다.** 기존 `text-transform: uppercase` +
`letter-spacing: .12em` 조합은 한글에 적용되지 않으면서 영문 라벨만 튀게 만들었다.

수치는 tabular figures 를 쓴다(코드에서 `font-variant-numeric: tabular-nums`).

## 밝기 - 2026-09-10 두 차례 상향

초안이 너무 어둡다는 지적을 받아 램프 전체를 두 단계 올렸다. 근-검정에서 그래파이트로
옮겼고, 무채색 크롬 규칙과 원인 색 8종은 건드리지 않았다.

실제 렌더 픽셀 측정(상단바 / 보드):

| 단계 | 상단바 | 보드 |
|---|---|---|
| 초안 | `(23,24,26)` | `(10,11,12)` |
| 1차 | `(33,36,41)` | `(21,23,26)` |
| 2차 (현재) | `(42,46,51)` | `(30,33,37)` |

**축소된 스크린샷으로는 이 차이가 보이지 않는다.** 눈으로 판정하지 말고 픽셀을 재라.

변수에 묶이지 않은 리터럴이 남아 있어 토큰만 올리면 따라오지 않는다. 함께 올릴 것:
노드 저하도 램프(`0.195 + d*0.36`), 지형 플레이트, 마커, 라벨 칩, 콜아웃, 컨트롤 클러스터.
