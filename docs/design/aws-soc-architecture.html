데이터 흐름

단계무슨 일이 일어나나
1방문자 접속CloudFront 뷰어 함수가 basic auth 를 검사하고 authorization 헤더를 지운다 (ADR-0029 5항, 그대로)
2WAF 판정유량 제한과 관리형 규칙이 허용 또는 차단을 정한다. 이것이 진짜 보안 이벤트의 출처다
3로그 적재WAF 로그는 CloudWatch Logs 로 7일. 기존 S3 접근 로그 90일은 사후 분석용으로 그대로 둔다
4SOC 가 폴링브라우저가 /api/soc/events?since= 를 주기적으로 부른다
5Lambda 정규화Logs Insights 로 최근 구간을 질의하고, IP 를 솔트와 함께 해시한 뒤 OCSF 로 바꿔 돌려준다
6큐에 표시운영 배지를 달고 경보 큐에 들어간다. 시나리오 경보와 섞이되 출처가 구별된다
ADR-0029 8항을 정면으로 건드린다. 그 항은 차단된 요청을 따로 남기지 않기로 했고, 근거는 "차단된 사람 목록이 되는데 시연 사본에서 그 기록으로 할 일이 없다" 였다. 이번 요청이 바로 그 할 일이다. 규칙을 어기는 것이 아니라 전제가 바뀐 것이고, 개정 근거는 그것이다. 다만 그 항이 걱정한 개인정보 문제는 그대로이므로 아래 넷으로 답한다.

개인정보를 다루는 방식

통제내용
원본 IP 는 브라우저에 안 간다Lambda 가 솔트와 함께 해시해서 내보낸다. 화면에 뜨는 것은 a3f1c2 같은 짧은 지문이고, 같은 방문자를 묶어 보기에는 충분하되 되돌릴 수 없다. 테스트로 고정한다
WAF 로그는 7일접근 로그 90일보다 짧게 간다. "차단된 사람" 쪽이 더 민감하기 때문이다
국가 코드는 보관만ADR-0002. CloudFront 가 국가를 주지만 어떤 판단에도 안 들어간다. 집계 위젯에도 안 쓴다
docs/05 에 등재수집 항목, 보존 기간, 파기 방법을 데이터 수명주기 문서에 적는다

연동은 세 단계로 간다

단계넣는 것비용
1단계 지금WAF · CloudTrail 관리 이벤트 · CloudWatch Logs거의 0. 관리 이벤트는 리전마다 추적 1개가 무료이고 90일 이벤트 기록은 이미 켜져 있다. S3 저장 요금만 붙는다
2단계 연동 확장GuardDuty · EventBridge30일 무료 체험. 그 뒤 CloudTrail 관리 이벤트 100만 건당 $4.00 이고 이 계정은 월 수만 건 규모다. VPC 가 없어 흐름 로그 과금도 없다
3단계 상시 운영Security Hub · AWS Config여기서만 비용 바닥이 생긴다. CSPM 이 AWS Config 를 요구하고 Config 는 기록하는 구성 항목마다 과금한다. 요금제가 바뀌는 중이라 켤 때 다시 확인한다
앞 단계가 뒷 단계의 입력이다. GuardDuty 는 CloudTrail 을 먹고 판정하므로 1단계 없이 2단계가 없다. 그리고 자동 대응(SOAR)은 어느 단계에도 없다 - 탐지가 조치를 직접 부르는 경로를 만들지 않는다 (ADR-0004). GuardDuty 가 탐지해도 EventBridge 는 그것을 SOC 큐로 보낼 뿐이다.
앞 설계서의 실측 배지를 시나리오 로 고쳐 쓴다. 진짜 운영 데이터가 들어오는 마당에 리플레이를 실측이라 부르면 둘 중 어느 쪽이 진짜인지 흐려진다.

그래도 안 넣는 것과 그 이유

서비스왜 미루나
CloudTrail 데이터 이벤트관리 이벤트와 달리 무료 사본이 없다. S3 객체 하나하나를 기록하는 것이고 우리 질문은 그 수준이 아니다
CloudTrail Lake2026-05-31 부터 신규 고객을 받지 않는다. AWS 가 CloudWatch 를 대신 권하고 이 설계가 이미 그 길이다
Data Firehose실시간 로그를 S3 로 흘리는 경로인데, 폴링으로 충분한 트래픽 규모에서 비용과 부품만 는다
Shield Advanced월 $3,000 이다. 시연 사본이 감당할 위협 모형이 아니다
자동 대응 (SOAR)탐지가 조치를 직접 부르는 경로를 만들지 않는다. ADR-0004. 이관은 건의이고 실행은 사람이다
Bedrock모델은 Anthropic API 를 직접 부른다. Bedrock 으로 가면 어댑터 뒤에 두고 Ollama 경로를 함께 유지한다 (ADR-0029 가 이미 그렇게 적어 뒀다)
이 저장소의 어떤 스크립트도 AWS 자원을 만들지 않는다. ADR-0029 가 정한 자세이고 그대로 간다. infra/demo-static.yaml 에 WAF 와 두 Lambda 를 조건부 리소스로 추가하되, 스택을 치는 것은 사람이다.

AWS Architecture Icons 는 AWS 가 배포하는 자산 패키지다. 아키텍처 도면 용도로 쓰며 아이콘을 변형하지 않는다. AWS 밖의 것에는 AWS 아이콘을 붙이지 않는다. 라이선스와 재배포 가능 여부는 docs/01-datasets.md 에 등재한다.
