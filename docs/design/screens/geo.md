# 화면: 관측 · 지리

Figma `MC-CyCOP UI Redesign` (`mwTJW4NKL4T3W44lnn6qCR`), 프레임 `관측 · 지리 (1600)`
(node `11:2`). 캔버스 1220×804, 플레이트 1220×740, 정보 바 1220×64.

지리는 **기본 뷰가 아니다.** 상단 뷰 전환의 세 번째 탭이다 (ADR-0001).

## 개편 전 결함과 처리

| 결함 | 처리 |
|---|---|
| 좌하단 `BFT-GW`/`TOC-SRV`/`TOC-WS` 라벨이 겹쳐 판독 불가 | **군집 축약.** 마커 하나 + 개수 배지 `3` + 요청 시 펼치는 콜아웃 목록 |
| `SAT-TERM`/`BN-CP` 라벨 충돌 | 유닛마다 라벨 방향(L/R/T/B)을 명시 배치 |
| 하단 축척·범례·면책이 한 줄에서 겹치고 우측이 잘림 | **슬롯형 정보 바.** 오토레이아웃 + 수직 구획선이라 겹침이 구조적으로 불가능 |
| 지도가 레터박스로 갇혀 공간 낭비 | 플레이트를 full-bleed 로 |
| 3D 전용 슬라이더 3개가 2D 에서도 자리 차지 | 2D 에서 숨기고 "회전·고도각·표고는 3D 에서" 한 줄로 대체 |

## 라벨 배치 규칙

- 마커 26×26, 라벨 칩은 마커에서 8px 떨어뜨린다.
- 방향은 유닛별로 고정한다. 자동 배치에 맡기지 않는다.
- 밀집 구역은 **개수 배지가 달린 단일 마커**로 접고, 지시선으로 콜아웃을 연결한다.
- 칩에는 반투명 배경판을 깐다. 등고선 위에서도 읽혀야 한다.

## 정보 바 슬롯

`시나리오 | 격자 | 등고선 | 가시선 차폐 | 앵커 | (여백) | 면책`

면책은 우측 정렬 2줄이다. **주황(=미상)으로 강조하지 않는다.** 경고가 아니라 단서다.

## 미해결

- **마커 안이 비어 있다.** 실제 심볼은 milsymbol 이 런타임에 SVG 로 그린다(ADR-0018).
  시안은 자리만 잡았다. 2525 심볼 라이브러리 구성은 별도 작업이다 (ADR-0013).
- 3D 자세(회전/고도각/표고 과장) 화면 시안 없음.
- 등고선·음영기복은 시안용 근사다. 실제는 `ui/src/terrain.js` 의 보간값이다.

## Figma 작업 중 걸린 것

프레임을 `clone()` 한 뒤 `setBoundVariableForPaint` 로 색을 다시 칠하면 **별칭이
해석되지 않고 검정으로 렌더된다.** 베이스 페인트에 리터럴 색을 같이 넣어야 한다.
`{r:0,g:0,b:0}` 를 베이스로 넘기는 문서 예제를 그대로 쓰면 복제본에서 글자가 사라진다.

## 3D 자세 화면

프레임 `관측 · 지리 3D (1600)` (node `21:2`).

- 지형은 **투영 와이어프레임 메시**다. 등고 방향 18줄(올리브), 교차 방향 26줄(청회색),
  능선 2줄을 강조한다. 지면 기준면은 파선 사각형으로 남긴다.
- 투영: 방위 35°, 고도각 55°, 표고 과장 ×12. 화면 좌표는
  `x = OX + xr*0.82`, `y = OY + yr*cos(pitch)*0.86 - Z*sin(pitch)`.
- 유닛은 **지면에서 지표면까지 파선 지주(stem)**로 잇는다. 고도를 읽을 수 있어야 한다.
- 2D 에서 숨겼던 슬라이더 3개(회전·고도각·표고 과장)가 여기서 보인다. 값 라벨을 붙였다.

### 미해결

- 메시가 화면 위쪽에 몰려 하단 여백이 크다. 투영 원점(`OY`) 재조정 필요.
- 지주가 지표면 아래를 지날 때 가려짐(occlusion) 처리가 없다. 와이어프레임이라 티가
  덜 나지만, 면을 채우면 문제가 된다.
- 3D 에서의 라벨 겹침 회피는 2D 와 다른 규칙이 필요하다. 지금은 수동 배치다.
