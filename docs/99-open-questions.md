# 99. 미확정 사항

작업이 이 갈림길에 닿으면 진행 전에 확인한다. 확정되면 해당 항목을 ADR로 승격시키고
이 문서에서 지운다.

## Q1. 대상 망: 국방망 vs 전술망 ★최우선

| | 국방망 (행정/엔터프라이즈 유사) | 전술망 (무전, 전술 C2, 대역폭 제약) |
|---|---|---|
| 공개 데이터셋 적합성 | OpTC/LANL/AIT가 거의 그대로 매핑 | 부적합 |
| 대안 경로 | — | AIT 테스트베드 재생성으로 토폴로지 직접 구성 (사실상 유일한 현실적 경로) |
| 임무 모델 | 정적 그래프로 충분 | **시간에 따라 변하는 그래프** 필요 (노드 이동·연결 변화) |
| 상황도 요구사항 | 표준 웹 UI | 저대역폭 동기화, 간헐 연결(DIL) 대응 |
| 난이도 | 중 | 상 |

**영향 범위가 가장 크다.** 전술망이면 `01-datasets.md`의 주력 데이터셋 순위가 통째로 바뀌고
`03-mission-ontology.md`에 시간축이 추가된다.

## Q2. 심볼 체계: MIL-STD-2525 준용 여부

- 준용 시: `Asset.type` → 심볼 코드 매핑 테이블 필요. 사이버 도메인 심볼 확장 방식 검토 필요.
  군 심사에서 친숙성·정합성 점수를 얻는다.
- 미준용 시: 자체 심볼 체계. 임무 그래프 표현에는 오히려 자유롭다.
- 절충안: 지리 레이어(보조 뷰)에서만 2525 준용, 임무 그래프 뷰는 자체 체계.
  **현재 이 절충안이 유력하다고 보나 확정 아님.**

## Q3. 산출물 성격의 우선순위

- 학위논문 / 과제 제안서 / 프로토타입 데모 중 무엇이 1순위인가.
- 학위논문이면 E4(사용자 실험)와 평가 엄밀성이 중요해지고, 제안서면 아키텍처와 근거 문서가,
  데모면 UI와 시나리오 완성도가 중요해진다.
- 일정 배분이 여기서 갈린다.

## Q4. LLM 배치 형태

- 온프렘 전제는 확정(ADR-0007). 다만 구체적 사양이 미정.
- 가용 GPU? 이에 따라 후보 모델 크기(7B/14B/30B+)와 지연 예산이 정해진다.
- 개발 중에는 API 모델을 쓰되 어댑터 뒤에 두고, 평가는 온프렘 후보로 한다 — 이 방식이
  현실적이나 확정 필요.

## Q5. UI 구현 스택

- Figma MCP가 연결되어 있어 디자인은 Figma에서 진행 가능. 단 현재 좌석 기준
  **읽기 도구 월 20회 제한**이라 반복 작업에 부적합. (`06-design-workflow.md` 참조)
- 그래프 렌더링 라이브러리 선정 미정 (Cytoscape.js / Sigma.js / deck.gl 등).
  노드 수천 개 규모에서의 성능이 선정 기준.

- 몇 명을 어떻게 확보할 것인가. IRB/윤리 심의 대상 여부 확인 필요.
