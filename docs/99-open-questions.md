작업이 이 갈림길에 닿으면 진행 전에 확인한다. 확정되면 해당 항목을 ADR로 승격시키고
이 문서에서 지운다.

## ~~Q1. 대상 망~~ → **확정: 전술망** (2026-09-06, [ADR-0012](adr/0012-target-network-is-tactical.md))

임무 그래프에 시간축이 들어가고, 데이터셋 순위는 OpTC > LANL > AIT로 조정됐다.
새 요구사항으로 **기동·지형에 의한 단절과 공격에 의한 저하를 구분**하는 문제가 생겼다.

> 당시 이 표에 "대안 경로: AIT 테스트베드 재생성이 사실상 유일한 현실적 경로"라고
> 적었는데 **틀렸다.** Kyoushi Testbed Environment는 OpenStack에 30 vCPU / 디스크 800GB /
> RAM 60GB를 요구한다. 가용 장비는 워크스테이션 1대(전체 RAM 63.7GB)다. ADR-0012 5항.

## ~~Q2. 심볼 체계~~ → **확정: 2525 준용** (2026-09-06, [ADR-0013](adr/0013-adopt-mil-std-2525-symbology.md))

`Asset.type` → SIDC 매핑 테이블이 필요하고, 렌더링 스택이 웹 쪽으로 제약된다(Q5에 반영).
사이버 고유 상태는 아이콘을 새로 그리지 않고 상태·증정보 계층에 얹는다.

## ~~Q3. 산출물 우선순위~~ → **확정: 데모 1순위, 논문 2순위** (2026-09-06, [ADR-0014](adr/0014-demo-first-then-paper.md))

작업 순서가 재배열됐다: 시간축 온톨로지 → 2525 심볼 → 상황도 UI → what-if →
LLM 브리핑 → 탐지 실험. **AIT 취득을 중단한다.** E4는 뒤로 미루되 설계는 남긴다.

## ~~Q4. LLM 배치 형태~~ → **확정: 로컬 GPU, 4비트 7~14B** (2026-09-06, [ADR-0016](adr/0016-local-gpu-llm-sizing.md))

RTX 2080 Ti **11GB**(Turing sm_75), Xeon W-2123 4코어, RAM 63.7GB. 상한 14B이고
런타임은 GGUF + llama.cpp 계열. Colab은 배포 형상과 어긋나 평가·데모 경로에서 제외한다.

## Q5. UI 구현 스택 ★최우선 (Q3 확정으로 승격)

> ADR-0014(데모 1순위)로 **긴급해졌고**, ADR-0013(2525 준용)이 이미 선택지를 좁혔다.

- **2525/APP-6 심볼 렌더러가 있는 스택이어야 한다.** 심볼을 직접 그리는 것은 비현실적이다.
  `milsymbol` 계열 오픈소스 JS 렌더러가 후보이며, 이는 **웹 스택**을 강하게 시사한다.
- 그래프 렌더링 라이브러리 선정 미정 (Cytoscape.js / Sigma.js / deck.gl 등).
- 선정 기준에 **심볼 렌더링을 포함한 성능**을 넣는다. 노드 수천 개에 SVG 심볼을 그리면
  느려진다. 심볼 없는 벤치마크는 의미가 없다.
- 전술망(ADR-0012) 요구로 **저대역폭 델타 동기화와 오프라인 동작**이 추가 기준이다.
- Figma는 좌석 기준 읽기 도구 월 20회라 반복 작업에 부적합 (`06-design-workflow.md`).

## ~~Q6. 전문가 평가~~ → **확정: 수행하지 않음** (2026-09-06, [ADR-0015](adr/0015-no-human-subject-evaluation.md))

E4 전체와 E2의 전문가 순위 상관을 폐기하고 **계산 가능한 대조**로 대체한다 —
경보 심각도 순위와 임무 저하도 순위의 **불일치도**(Kendall tau / top-k 겹침률).
"더 낫다"가 아니라 **"다른 답을 낸다"**만 주장한다. IRB 확인은 불필요해졌다.
