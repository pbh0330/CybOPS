# ADR-0012. 대상 망은 전술망이다

**상태**: 채택 (2026-09-06)

`99-open-questions.md` Q1을 확정한다. 이 문서로 Q1을 대체하고 해당 항목은 삭제한다.

## 맥락

대상 망이 국방망(행정/엔터프라이즈 유사)인지 전술망(무전, 전술 C2, 대역폭 제약)인지에
따라 임무 그래프 구조와 데이터셋 순위가 동시에 갈린다. 과제 책임자가 **전술망**으로
확정했다.

## 결정

**대상 망은 전술망이다.** 이에 따라 다음을 확정한다.

### 1. 임무 그래프에 시간축을 넣는다

정적 그래프로는 전술망을 표현할 수 없다. 노드가 이동하고 링크가 끊겼다 붙는다.

- 노드·엣지에 **유효 구간**을 붙인다. 자산은 임무 단계(phase)별로 가용/비가용이 갈린다.
- 임무를 단계로 분해하고, 각 단계마다 별도의 의존 그래프 스냅샷을 갖는다.
- 저하도 계산은 "시점 t의 그래프"에 대해 수행한다. 지금 구현된 정적 전파 엔진
  (`scripts/Invoke-MissionPropagation.ps1`)은 단일 스냅샷 전파로 재해석하고,
  그 위에 시간축을 얹는다. 폐기하지 않는다.

### 2. 새 요구사항: 공격에 의한 저하와 이동에 의한 단절을 구분한다

국방망에는 없던 문제다. 전술망에서 링크가 죽는 흔한 이유는 공격이 아니라 **기동과
지형**이다. 이를 구분하지 못하는 상황도는 **언덕을 적의 소행으로 보고한다.**

- 링크 상태 변화에는 원인 라벨이 필요하다: `attack` / `mobility` / `terrain` / `unknown`.
- 원인이 `unknown`일 때 공격으로 단정하지 않는다. 이는 ADR-0003(상태 산출은 결정론
  계층 전담)의 연장이며, 여기서도 LLM에 판정을 맡기지 않는다.
- 이 구분은 **평가 항목이 되어야 한다.** 기동으로 끊긴 링크를 공격으로 오탐하는 비율을
  별도 지표로 본다.

### 3. L1 텔레메트리는 여전히 엔터프라이즈다 — 숨기지 않는다

공개 데이터셋 중 그라운드트루스를 갖춘 **전술망 데이터는 존재하지 않는다.**
LANL·OpTC·AIT는 전부 엔터프라이즈 IT 망이다.

따라서 계층별로 출처를 분리해 명시한다.

| 계층 | 출처 | 전술망인가 |
|---|---|---|
| L1 텔레메트리 | 공개 데이터셋 (LANL / OpTC) | **아니다. 엔터프라이즈다** |
| L2 임무 온톨로지 | 직접 설계 (시간축 포함) | 그렇다 |
| L3 시뮬레이션 | 합성 시나리오 | 그렇다 |

**"전술망 텔레메트리로 검증했다"고 쓰지 않는다.** 쓸 수 있는 주장은
"임무 계층을 전술망 구조로 설계하고, 탐지 계층은 공개 엔터프라이즈 텔레메트리로
평가했다"까지다. 이 한계는 논문 본문에 적는다 — 심사자가 데이터셋을 열어보면 즉시 드러난다.

이 구조는 원래 설계와 어긋나지 않는다. L2에 공개 데이터가 없다는 것은 처음부터 전제였고,
전술망 확정은 그 간극을 **넓혔을 뿐 새로 만들지 않았다.**

### 4. 데이터셋 순위를 조정한다

| 순위 | 데이터셋 | 근거 |
|---|---|---|
| 1 | **OpTC** | 호스트 텔레메트리 + **명시적 피벗 연쇄**. 전술 C2 단말도 결국 Windows 호스트다. E1-b의 유일한 근거(ADR-0011) |
| 2 | **LANL** | 대규모 인증 이벤트, CC0, 이미 취득·검증 완료(5/5). AD 도메인 중심이라 전술망 전이성은 낮지만 유일하게 완결된 실데이터다 |
| 3 | **AIT** | 메일/WordPress/VPN/방화벽 등 **기업 IT 테스트베드**. 전술망 전이성이 셋 중 가장 낮다 |

### 5. AIT 재생성 경로는 이 하드웨어에서 불가능하다

`99-open-questions.md`는 "AIT 테스트베드 재생성으로 토폴로지 직접 구성"을 전술망의
**"사실상 유일한 현실적 경로"**라고 적었다. **틀렸다.**

Kyoushi Testbed Environment는 OpenStack 위에서 **최소 30 vCPU, 디스크 800GB,
RAM 60GB**를 요구한다. 가용 장비는 워크스테이션 1대이고 전체 RAM이 63.7GB다.
RAM만으로도 성립하지 않는다.

전술망의 현실적 경로는 재생성이 아니라 **L2를 직접 설계하는 것**이다. 이미 그렇게 하고
있다(`scenarios/defnet-01/`). 전술망 확정으로 달라지는 것은 그 설계에 시간축과 기동
모델이 들어간다는 점이다.

### 6. DIL 제약이 LLM 배치를 강하게 구속한다

전술망은 Disconnected / Intermittent / Limited다.

- ADR-0007(온프렘 + 모델 어댑터)이 선택지가 아니라 **필수**가 된다. 클라우드 API는
  전술 환경에서 가정할 수 없다.
- 모델 크기 상한이 엣지 하드웨어로 정해진다 → Q4(LLM 배치 형태)의 답이 좁아진다.
- 상황도는 **저대역폭 동기화와 간헐 연결**을 전제로 설계한다. 전체 그래프를 매번
  내려받는 UI는 성립하지 않는다. 델타 동기화와 오프라인 동작이 요구사항이다.

## 근거

- 전술망에서 링크 단절의 지배적 원인이 기동·지형이라는 점은 상황도의 신뢰도를 직접
  좌우한다. 오탐 하나가 아니라 **화면 전체의 신뢰**가 걸린다. ADR-0002에서 지오로케이션을
  판단 경로에서 배제한 것과 같은 종류의 판단이다.
- 전술망 공개 데이터가 없다는 것은 회피할 수 없는 사실이므로, 숨기는 대신 계층별 출처를
  명시하는 편이 방어 가능하다. ADR-0008(accuracy 금지)과 같은 태도다.

## 결과

- `03-mission-ontology.md`에 시간축 스키마를 추가해야 한다.
- `04-evaluation.md`에 "기동 단절을 공격으로 오탐하는 비율" 지표를 추가해야 한다.
- `01-datasets.md`의 순위를 위 4항으로 갱신한다.
- **AIT 잔여 123GB(7개 파일)의 취득 가치가 떨어졌다.** 현재 받는 중인
  `russellmitchell.zip` 하나는 파이프라인 검증 표본으로 끝까지 받되, 나머지 7개는
  착수 전에 재검토한다. 회선이 0.6~1.0 MB/s라 123GB는 며칠이고, 그 시간은 OpTC
  최소 세트(`09-optc-acquisition.md`)에 쓰는 편이 낫다.
- Q2(MIL-STD-2525 준용)의 중요도가 올라간다. 전술망이면 군 사용자의 심볼 친숙성이
  국방망보다 직접적으로 작용한다.

## 대안

- **국방망으로 잡고 전술망은 확장으로 언급**: 기각. 과제 책임자가 전술망으로 확정했다.
- **전술망 데이터셋을 찾아본다**: 기각. 그라운드트루스를 갖춘 공개 전술망 데이터셋은
  확인되지 않는다. 없는 것을 찾는 데 일정을 쓰지 않는다.
- **Kyoushi로 전술 토폴로지를 재생성**: 기각. 하드웨어 요구가 가용 장비를 초과한다(5항).
  단, 향후 클라우드 자원이 확보되면 재검토 대상이다.

## 재검토 조건

- 전술망 계열의 공개 데이터셋이 그라운드트루스와 함께 공개되는 경우.
- OpenStack 클러스터급 자원이 확보되어 Kyoushi 재생성이 가능해지는 경우.
- 과제 요구가 국방망으로 변경되는 경우 — 이 ADR을 폐기하고 새 ADR을 쓴다.
