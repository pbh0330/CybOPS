# ADR-0024. 상황도 UI 개편 - 무채색 크롬, 채널 분리, React 도입

**상태**: 채택 (2026-09-10)

ADR-0018(Cytoscape.js + Vite 정적 번들)을 **대체하지 않는다.** 그 결정은 그대로 살아 있고
이 문서는 그 위에 얹는다.

## 맥락

동작하는 UI(`ui/`)를 실사용 화면으로 보다가 세 가지가 걸렸다.

**1. 브랜드 강조색이 원인 색과 충돌했다.** `--accent: #35e0ff` 와 `--mobility: #35c8ff`.
사실상 같은 색이다. 화면에서 "장식"과 "기동이 원인이다"가 구분되지 않았다. ADR-0012 가
색에 의미를 실어 놓았는데 크롬이 같은 색 공간을 쓰고 있었다.

**2. 저하도 색 램프가 빨강에 닿을 수 있었다.** 규칙은 "노드 색은 임무 저하도, 테두리는
원인"인데, 저하도를 색상환으로 표현하면 심각한 저하가 빨강이 된다. 그러면
"붉은색은 공격에만 쓴다"가 깨진다.

**3. 정보 위계가 뒤집혀 있었다.** `0.0%` 가 화면에서 가장 큰 글자였다. 아무 일도 없는
상태가 최대 시각 비중을 먹었다.

## 결정

### 1. 채도는 의미에만 쓴다

크롬(상단바·레일·버튼·탭·시간축·패널)에 **유채색을 쓰지 않는다.** 화면에서 채도를
가진 것은 원인 색 8종뿐이다.

이 규칙이 ADR-0012 를 색 체계 수준에서 강제한다. 지키는지 눈으로 볼 수 있다 -
크롬에 색이 보이면 위반이다.

### 2. 저하도는 휘도, 원인은 테두리

- **저하도**: 무채색 휘도 램프. 밝을수록 나쁘다. 색상 없음.
- **원인**: 테두리 색. 공격은 파선을 더한다.

기존 규칙("색=저하도, 테두리=원인")을 유지하되 저하도 채널에서 색상을 제거한 것이다.
빨강은 공격 전용으로 남는다.

**봉쇄 비용도 빨강을 쓰지 않는다.** "격리 시 임무 +8.2%p"는 나쁜 숫자지만 공격이 아니다.
크기로 무게를 준다.

### 3. 대문자 트래킹 라벨을 쓰지 않는다

기존 `text-transform: uppercase` + `letter-spacing: .12em` 은 한글에 적용되지 않으면서
영문 라벨만 튀게 만들었다. 한글·영문이 섞이는 화면에서 쓸 수 없는 장치다.

### 4. 렌더링은 React 로 옮긴다

**ADR-0018 의 결정 사항은 전부 유지된다**: Cytoscape.js, milsymbol SVG, dagre 레이아웃,
`vite build` 정적 번들, 서버 없음, CDN 미의존. ADR-0018 은 프레임워크를 규정하지 않았다.

바꾸는 것은 DOM 계층뿐이다. `ui/src/main.js` 1,273 줄이 명령형 DOM 조작과 상태 동기화를
손으로 하고 있었고, 모드 3개(관측·편집·교전) × 뷰 3개(의존·전송로·지리) × 시간축이
곱해지면서 갱신 경로가 뒤엉켰다.

**엔진·그래프·지형·워게임·공격 모듈은 건드리지 않는다.** 프레임워크 무관한 순수 로직이고,
ADR-0003(상태 산출은 결정론 엔진) 경계와 정확히 일치한다. React 는 그 결과를 그릴 뿐이다.

### 5. 타이포는 IBM Plex Sans KR

Pretendard 는 Figma 에 없어 시안을 만들 수 없었다. IBM Plex Sans KR 은 한글을 지원하고,
오픈소스라 온프렘 자체 호스팅이 되고(ADR-0007), CDN 을 안 쓴다는 ADR-0018 제약과도 맞는다.

## 결과

- 색 규칙 위반이 눈에 보인다. 크롬에 색이 있으면 잘못된 것이다.
- 저하도가 아무리 심해도 빨강이 되지 않는다. 빨강을 보면 공격이다.
- 갱신 경로가 상태에서 파생된다. 모드×뷰×시간 조합마다 손으로 동기화하지 않는다.
- **React 런타임이 번들에 추가된다: 실측 +142 kB** (1,480 -> 1,622 kB, gzip 453 kB).
  정적 번들·오프라인 동작은 유지된다. CDN 은 여전히 쓰지 않는다.
- 기존 `dist-hosted` 산출물은 재생성해야 한다.

## 대안

**바닐라 유지 + CSS 만 개편.** 색 문제는 풀리지만 갱신 경로 문제가 남는다. 교전 모드가
들어오면서 이미 한계였다.

**전면 재작성(Cytoscape 포함 교체).** 동작하는 것을 버릴 이유가 없다. ADR-0018 의 선정
근거(수백 노드 규모, milsymbol SVG 배경, 복합 노드)는 그대로 유효하다.

### 코드 단계에서 추가로 잡은 것

`graph.js`의 `degColor` 가 실제로는 **빨강 램프였다.** 주석에는 "Not a red ramp" 라고
적혀 있었지만 마지막 단계가 `#8f2f39` 였다. 심하게 저하된 노드와 공격받은 노드가 같은
색으로 보였다는 뜻이다. 무채색 휘도 램프로 교체했다.

`stylesheet()` 의 `node.link-src` 테두리도 `#35e0ff` 였다. 크롬의 옛 강조색이 그대로
남아 있었다.
