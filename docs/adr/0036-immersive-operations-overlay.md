# ADR-0036. 선택형 통합 작전 장면 위에 임무 분석을 겹친다

상태: 채택 (2026-11-10, 사용자 후속 요청). ADR-0035의 분할 배치를 확장한다.

## 맥락

사용자가 두 번째 영상과 함께 “영상 위에 MC-CyCOP을 얹는 느낌”이라고 설명했다.
작은 자산 관측 모형만으로는 이 의도가 충족되지 않는다.

## 결정

`통합 작전`은 지도와 큰 3D 환경 장면, 사이버 상태 패널, 공통 시간축으로 구성한다.
임무 의존 그래프와 사건 목록은 장면 위에 열 수 있다. 근접/전체/지구 카메라,
지도/장면 확대와 표시 전용 환경 설정을 제공한다. 기존 기본 그래프 진입은 유지한다.

Three.js와 MapLibre를 재사용하고, 외부 모델·원본 영상·데이터셋을 번들하지 않는다.
합성 해상/항공/우주 단말도 기존 사이버 유형으로 상태 엔진에 들어간다.
모형과 환경은 판단 엔진을 호출하거나 상태·연결·승인 결과를 덮어쓸 수 없다.

## 결과와 검증

3D 장면이 재생 중일 때 환경을 애니메이션하되 정지/숨김/감소된 동작 설정에서는 멈춘다.
WebGL 실패 시 지도·그래프·수치와 시간축을 계속 사용할 수 있게 한다.
시간/선택 동기화, 결측 위치, 표시 설정 불변성, 모델 자원 해제와 브라우저 조작을 검증한다.

## 대안과 재검토

영상 파일 위에 HTML만 얹는 방식은 상호작용·시점·자산 선택이 불일치하므로 채택하지 않는다.
기본 화면을 지리 중심으로 바꾸려면 ADR-0001을 별도로 논의한다.
실제 물리/실시간 피드가 필요해지면 데이터 출처·검증·배치에 관한 별도 설계로 다룬다.
