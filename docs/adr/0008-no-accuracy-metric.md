# ADR-0008. 평가에 accuracy 사용 금지

**상태**: 채택 (2026-09-05)

## 맥락

이 과제가 쓰는 데이터의 악성 이벤트 비율은 극단적으로 낮다.

| 데이터셋 | 악성 비율 |
|---|---|
| LANL | 전체 이벤트 중 0.0000713% |
| DARPA TC 평가 구간 | 약 0.0016% |
| OpTC 공격 흔적 상위 3개 호스트 | 악성 노드 0.024% |

"전부 정상"이라고 답하기만 해도 accuracy 99.99% 이상이 나온다.

## 결정

**accuracy를 주지표로도 보조지표로도 보고하지 않는다.**

주지표: PR-AUC, precision@k, recall@FPR, MTTD, alert volume reduction.
LLM 계층은 별도 지표군을 쓴다(`../04-evaluation.md`).

ROC-AUC는 이 정도 불균형에서 낙관적으로 부풀려지므로 보조로만, 그리고 PR-AUC와 함께만
보고한다.

## 근거

- 위 표의 불균형 수준에서 accuracy는 정보량이 사실상 0이다.
- SOC 우선순위 결정에서 LLM의 precision이 일관되게 낮다는 실측이 있다. precision을 직접
  보지 않으면 이 실패 모드가 accuracy 뒤에 숨는다. 불균형과 겹쳐 이중으로 위험하다.
- precision@k는 SOC 현실에 대응한다. 분석관이 하루에 볼 수 있는 건수가 k다.

## 결과

- 베이스라인 비교가 필수가 된다(규칙, Linear SVM, GBDT). 선행 실측에서 Linear SVM
  베이스라인이 전체 F1 최고를 기록한 사례가 있으므로, 이를 이기지 못하면 복잡한 구성은
  정당화되지 않는다.
- 논문 표에 accuracy 열을 넣지 않는다. 심사자가 물으면 이 ADR로 답한다.

## 대안

- **accuracy를 참고로 병기**: 기각. 병기하면 인용될 때 그 숫자만 떨어져 나간다.

## 재검토 조건

없음. 데이터 성질이 바뀌지 않는 한 유효하다.
