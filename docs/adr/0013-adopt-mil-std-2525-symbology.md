# ADR-0013. MIL-STD-2525 심볼 체계를 준용한다

**상태**: 채택 (2026-09-06)

`99-open-questions.md` Q2를 확정한다.

## 맥락

대상 망이 전술망으로 확정되면서(ADR-0012) 군 사용자의 심볼 친숙성이 국방망 가정보다
직접적으로 작용하게 됐다. 기존 문서는 "지리 레이어만 2525 준용, 임무 그래프 뷰는 자체
체계"라는 절충안을 유력하다고 적어뒀으나 확정은 아니었다.

과제 책임자가 **준용**으로 확정했다.

## 결정

**MIL-STD-2525(및 NATO APP-6 대응)를 준용한다.**

적용 범위를 다음과 같이 나눈다.

### 1. 실체가 있는 자산 - 표준 심볼을 그대로 쓴다

부대, 차량, 지휘소, 통신소 등 물리 실체가 있는 노드는 표준 심볼 식별 코드(SIDC)로
표현한다. 소속(아군/적/중립/미상), 상태, 계층 증정보(amplifier)를 표준 의미대로 쓴다.

`Asset.type` → SIDC 매핑 테이블을 만든다. 이 테이블은 온톨로지 스키마의 일부다
(`03-mission-ontology.md`).

### 2. 사이버 고유 상태 - 아이콘을 새로 그리지 않는다

"침해됨", "임무 저하 55%" 같은 사이버 고유 의미는 **표준에 대응 심볼이 없거나 불확실하다.**
여기서 자체 아이콘을 만들면 준용의 이점(친숙성)을 스스로 없앤다.

따라서 **상태·증정보(status, amplifier, modifier) 계층에 얹는다.** 아이콘 자체는
표준을 유지하고, 사이버 상태는 색·테두리·부가 표기로 표현한다.

> **~~검증 필요~~ → 조사 완료 (2026-09-06). 아래 개정을 참조한다.**

#### 개정 (2026-09-06) - 방침은 유지, 근거는 뒤집힌다

조사 결과 **MIL-STD-2525D에 심볼셋 60 = Cyberspace(부록 L)가 이미 있다.**
`Device Type`(Mail/Web/Domain/File Server, Firewall, Switch, Host, Router, VPN 등),
`Health and Status`(Normal / Network Outage / Unknown / Impaired), `Effect`(Infection,
Degradation, Exfiltration, 각종 Outage)가 표준 심볼로 정의돼 있다.

따라서 "**표준에 없으니 상태 계층에 얹는다**"는 근거는 성립하지 않는다. 바뀌는 것과
유지되는 것을 나눠 적는다.

- **유지**: 자체 아이콘을 새로 그리지 않는다. 결론은 그대로다.
- **변경**: 사이버 상태는 임의 표기가 아니라 **표준 심볼(Effect > Infection / Degradation)**
  로 표현한다.
- **새 제약**: 엔터티 자릿수가 하나뿐이라 `Domain Server` + `Impaired`를 **한 SIDC로
  합칠 수 없다.** 장비 심볼 옆에 상태 심볼을 **병기**해야 한다.
- **주의**: 2525E가 심볼셋 60의 코드를 재배정한 정황이 있다. 버전을 고정하지 않은 SIDC를
  저장하면 렌더러가 편집판을 자동 판별해 **아이콘이 조용히 바뀐다.** 매핑 파일은
  **2525D로 고정**한다.

매핑 테이블은 `configs/symbology-2525.json`, 조사 근거와 미검증 항목 목록은
[12-symbology-mapping.md](../12-symbology-mapping.md)에 있다. **코드는 아직 표준 원문
대조 전이다**(공개 인코딩·오픈소스 렌더러 교차 확인까지만 됐다). 원문 대조가 끝나기 전에는
논문에 표준 준수를 주장하지 않는다.

### 3. 임무 그래프 뷰 - 심볼과 위상을 분리한다

임무 그래프는 지도가 아니다(ADR-0001). 노드 배치는 의존 위상이 정하고, **노드에 그려지는
그림만** 2525 심볼을 쓴다. 즉 심볼 체계는 준용하되 좌표계는 준용하지 않는다.

이 구분을 흐리면 ADR-0002(지오로케이션 배제)가 무너진다. 심볼이 익숙하다고 해서 화면을
지도로 되돌리지 않는다.

## 근거

- 전술망 사용자는 2525/APP-6에 이미 훈련되어 있다. 자체 체계는 학습 비용을 새로 만든다.
- E4(상황인지 비교 실험)에서 "임무 그래프가 낯설어서 느렸다"는 교란 요인을 줄인다.
  심볼을 표준으로 맞추면 비교 대상 간 차이가 **좌표계**로 좁혀진다.
- 군 심사에서 정합성 점수를 얻는다.

## 결과

- `Asset.type` → SIDC 매핑 테이블이 온톨로지 스키마에 추가된다.
- **렌더링 스택 선택이 제약된다(Q5).** 2525/APP-6 심볼을 직접 그리는 것은 비현실적이므로
  기존 렌더러를 쓴다. `milsymbol` 계열의 오픈소스 JS 렌더러가 후보이며, 이는 상황도를
  **웹 스택**으로 가는 쪽으로 밀어준다. Q5 결정 시 이 제약을 먼저 반영한다.
- 심볼 렌더링 성능이 그래프 규모 상한에 영향을 준다. 노드 수천 개에 SVG 심볼을 그리면
  느려진다 - Q5 선정 기준에 "심볼 렌더링 포함 성능"을 넣는다.
- 데모 우선순위(ADR-0014)와 맞물려 **조기에 필요하다.** 데모의 첫인상이 심볼이다.

## 대안

- **자체 심볼 체계**: 기각. 임무 그래프 표현에는 자유롭지만 친숙성을 버린다.
  전술망 대상에서 이 손실이 크다.
- **지리 레이어만 준용(기존 절충안)**: 기각. 임무 그래프가 주 화면인데 주 화면에
  비표준 심볼을 쓰면 준용의 실익이 거의 없다.

## 재검토 조건

- 2525/APP-6의 사이버 심볼 지원 범위를 확인한 결과가 위 2항 방침과 어긋나는 경우.
- 렌더링 성능이 목표 규모에서 실패하는 경우 - 심볼 단순화 수준을 다시 정한다.
